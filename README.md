### 算法联调与 ERP 接入约定

修改前阅读当前代码、本文及 [AGENTS.md](./AGENTS.md)。默认沿用已确认能力，不因个人偏好、代码整理或接入方便顺带删减功能、重做面板或改变操作流程。

| 协作场景 | 主要工作与需要保留的规则 |
| --- | --- |
| 算法同事调试消除笔 | 优先联调 [消除接口](#消除接口) 与验证真实消除效果；保留仅处理当前底图、同尺寸源图与 Mask、结果先预览再采用、取消和失败后可恢复的流程，不将新增图层合并为消除源图 |
| 前端同事适配 ERP | 优先通过 [宿主契约](#宿主系统接入) 接入业务图片、鉴权、检测、保存及审核回流，并处理容器布局与样式隔离；保留现有工具、编辑规则、选择／视野／历史恢复、确认后提交及防重复保存机制 |

可复现的缺陷应按已确认规则修复，并完成相关回归。ERP 或算法约束若确实要求改变已有功能范围或交互含义，先说明原因、影响和取舍，经明确确认后再修改并同步文档。新增功能也应先明确范围与既有能力的关系，避免连带改变无关模块。

涉及共享画布、历史、图层或公共控件时，按[验证方式](#验证方式)检查受影响的既有流程；算法效果和 ERP 业务闭环另行验收，不能仅以接口有响应或前端测试通过作为接入完成的依据。正式 ERP 接入使用普通生产构建，演示构建及模拟词规则的边界见[独立预览中的文案检测](#独立预览中的文案检测)。

## 快速启动

需要 Node.js 和 npm。当前 Vite 的 Node.js 要求为 `^20.19.0 || >=22.12.0`（20.x 需至少 20.19.0，或使用 22.12.0 及以上版本）；依赖安装以 `package-lock.json` 为准。

在项目根目录执行，以下为 Windows PowerShell 命令：

```powershell
npm ci
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
npm run dev:demo
```

其他 shell 可用 `[ -f .env ] || cp .env.example .env` 完成配置文件初始化；已有 `.env` 不要覆盖。不配置后端也可预览编辑界面，配置项见[消除接口](#消除接口)。

各本地入口默认使用 [http://127.0.0.1:4180/](http://127.0.0.1:4180/)，日常交付与用户验收尽量保持此地址。开发和构建预览均锁定所选端口；端口占用时停止启动，不自动改号。开发和回归可按需选择一个或多个其他空闲端口，见下方临时验证示例。支持 `?image=https://...` 指定初始图片，包含特殊字符的图片 URL 应编码；远程图片需要允许跨域读取。

| 用途 | 启动命令 |
| --- | --- |
| 日常演示与交互验收 | `npm run dev:demo`，使用 `demo` 模式，在当前进程内将 `VITE_ERASER_API_URL`、`VITE_DEFAULT_IMAGE_URL` 置空，不修改本地配置文件 |
| 使用普通环境配置开发 | `npm run dev` |
| 真实消除调试 | `npm run dev:production-test`，按下方[环境配置](#环境配置)读取本地接口及凭据 |
| 普通构建预览 | `npm run build` 后运行 `npm run preview` |
| 真实消除测试构建预览 | `npm run build:production-test` 后运行 `npm run preview:production-test` |

**4180 用于日常继续验收，其他端口可灵活用于临时验证。** 同一端口只运行一个服务，已有可用服务优先复用。开发过程中可自主并行启动其他端口，例如 `npm run dev:demo -- --port 4181`、`npm run dev:production-test -- --port 4182` 或 `npm run preview -- --port 4183`；无需为这些临时端口另行确认，验证结束后可关闭。

协作方将供用户验收的开发服务作为独立后台进程运行，完成修改后确保 4180 提供最新代码并继续保留；演示入口可直接通过 `node server/demoPreview.mjs` 后台启动。普通代码更新优先热更新；确需重启时恢复同一地址，重新确认页面及资源可访问。端口冲突不结束无关进程；若 4180 确实不可用，说明原因和本次临时地址。

后台运行不等于开机自启；电脑关机、重启或服务异常退出后需要重新启动。编辑草稿仍只在当前页面中，刷新页面可能丢失未提交内容，不能把预览服务常驻理解为草稿已保存。

### 独立预览中的文案检测与替换流程

本地开发主页及 GitHub Pages 演示构建的主页提供模拟文案检测与完整替换流程，无需额外页面或链接参数。标题下方显示“演示 · 模拟违禁词 durable、supreme”。添加文字并输入 `durable supreme`，确认“替换图片”后可在同一文字图层查看两个违禁词，也可分别放入不同文字图层体验问题定位；改为 `reliable` 再次替换，文案通过后继续当前选定的演示流程。无新增文案时跳过这一项，不声称完成文案检测。

标题旁提供“演示场景”选择，默认选中并首位展示“完整成功流程”，第二项为“仅新增文案检测”，其后保留等待较久、未回报具体阶段、图中文字未通过、检测服务失败、替换结果待确认和审核页面刷新失败。仍从“替换图片”预览并确认后体验，不增加独立检测按钮或页面；切换场景保留草稿，处理中不能切换。网址参数仅在打开页面时预选场景：`?replacement-demo=success` 可省略，`?replacement-demo=texts` 指定仅新增文案检测；未提供或无法识别的参数值均使用完整成功流程。

完整流程使用实际提交进度弹窗，依次演示新增文案、图片检测、保存和返回审核；等待较久场景可观察实际等待秒数，结果待确认提供查询，审核刷新失败只重试刷新。完成后点击“返回编辑”，草稿与历史仍保留。所有阶段均标明模拟及未保存，不请求真实检测、创建业务记录或替换任务图片；模拟成功不关闭编辑器。

模拟规则只匹配完整英文单词 `durable` 和 `supreme`，不区分大小写，同一图层返回全部命中的词并去重，不是正式违禁词规则。所有场景仍先检查新增文案；命中任意模拟词都会先提示文案问题，修改后再次替换才能继续选定场景。顶部按问题文字图层数汇总，各图层展示自身命中的词。图中文字未通过场景使用固定模拟问题说明，不代表真实 OCR 检测。

选择“仅新增文案检测”时，通过后只提示“文案检测通过。当前为演示，未保存到任务。”，保留草稿，不继续后续图片检测及保存演示；无新增文案时仅提示未保存。

普通 `npm run build` 为正式构建，禁用并移除固定测试词规则及流程模拟逻辑；即使没有宿主接口也不会自动启用演示。GitHub Pages 工作流明确使用 `--mode demo`，只用于公开前端演示，不能把该演示产物作为正式业务版本。

只有独立入口启用此模式。宿主提供 `window.pixelweaveIntegration` 或通过 React 传入 `integration` 时，真实服务优先，接口失败不会回退为模拟通过；未启用预览且没有宿主服务时仍提示未接入。开发测试页与模拟词规则不代表真实接口已联调。

### 消除结果固定样例（仅供演示）

本地开发（包括已配置真实消除 Key 的 `npm run dev:production-test`）与 GitHub Pages 演示构建，在独立页面的消除笔面板提供“查看消除结果示例”。无需创建选区或填写密钥，直接展示两张 2910 × 1800 的杯子示意图，可体验左右对比、同步缩放、拖动、100% 查看、适配及橙色标签区域定位。两图由原 970 × 600 版本等比放大 3 倍，画面内容不变，区域定位同步缩放，用于较大尺寸图片的查看体验。该查看入口与实际编辑草稿独立。

独立预览未指定图片时，默认工作图片使用同一张 2910 × 1800 的消除前样图（杯子旁有橙色标签），可直接编辑。宿主 `initialImage`、页面 `?image=` 和 `VITE_DEFAULT_IMAGE_URL` 按现有顺序优先；默认样图不覆盖它们，加载失败也不自动改用样图。初始仍无选区、不自动消除。默认载入仅请求消除前图片，消除后图片在打开示例时才加载。

弹窗明确显示“固定样例 · 效果示意，未调用消除服务”，只提供“关闭示例”；Esc 也只关闭示例，返回入口焦点。示例不采用到当前图片，不改变当前对象、选区、历史及画布视野，不请求消除或保存接口，不记录真实消除埋点。加载失败可重试或关闭；处理、确认、未完成选区等受限状态不能打开示例。

**无接口时的完整消除流程演示：** 仅当独立预览未配置消除接口、当前底图仍为内置的消除前样图且没有生效调色时，面板提供“选择示例标签区域”。点击后设置固定矩形选区，再点击原有“开始消除”，依次体验准备、模拟等待、结果预览及使用／放弃。各阶段明确标注固定样图演示，返回预置的消除后图片，不请求算法或记录真实消除埋点。

- 新增文字、图形及画笔保持独立，预览和最终成图按原规则合成可见内容。使用结果只更新当前草稿、清空本轮选区，可继续编辑或走替换演示；一次撤销恢复原底图、选区和新增内容，重做可恢复结果。
- 取消、失败和放弃均保留相应草稿与选区，不自动重试；预览重试复用已载入结果，采用失败可单独重试，迟到结果不能覆盖新一轮操作。流程预览中的 Esc 沿用正常结果弹窗规则，不直接放弃。
- 手动改动预设选区后，不套用固定结果；点击“选择示例标签区域”可重新设置，重复选择不新增历史。上传图片、明确指定的初始图片、已调色或已采用的底图不进入该流程；撤销采用／调色恢复适用的默认底图后，可重新演示。
- 已配置真实消除接口时，“开始消除”始终走真实接口，失败不回退为模拟；仍可通过独立查看入口浏览固定前后图。演示不代表算法质量、真实检测、持久化保存或 ERP 回流已完成。

**正式 ERP 接入不得携带固定样例。使用普通 `npm run build`，不要使用 `--mode demo` 的产物作为正式业务版本。** 普通正式构建会移除样例入口、演示逻辑及这两张样图，也不使用演示默认底图；接入真实宿主时，即使在本地开发环境也不显示该入口或以样图代替业务图片。保留正常的“检查消除结果”弹窗及真实消除流程，排除的是固定样例功能。

素材与生成说明位于 [docs/demo/eraser](./docs/demo/eraser/README.md)，通过受构建条件保护的动态模块按需加载，未放入 `public/`。正式接入时不要将该素材目录复制到 `public/`、ERP 静态资源或部署目录；若自行移植组件，也须排除 `EraseExampleEntry`、`src/demo/eraseExample.ts`、`src/editor/previewErase.ts` 及其演示调用分支。发布前分别检查普通正式构建没有示例入口、演示逻辑或图片文件，演示构建的样图路径可访问。

## 功能与操作

### 图片术语

| 名称 | 含义 |
| --- | --- |
| 初始原图 | 进入本次编辑时的图片，用于“按住查看原图”和“还原初始”；上传新图不改变这一基准 |
| 当前底图 | 当前工作的基础图片，可能已上传替换或采用过消除结果；消除源图由它生成，并包含当前调色效果 |
| 编辑结果 | 当前底图叠加可见新增内容后合成的图片，用于提交替换任务图片 |
| 消除选区（Mask） | 单独提交的修改区域，不加入普通图层列表，也不进入最终成图 |

### 编辑能力

| 模块 | 行为 |
| --- | --- |
| 图片 | 宿主或 URL 提供进入编辑时的图片；“上传本地图片”仅接受实际可解码的 JPG/JPEG，成功后载入新草稿，保留上传图片原尺寸 |
| 绘制入口 | 左侧统一为“绘制”，面板顶部直接切换画笔／矩形／椭圆；首次默认画笔，本次编辑中记住最近绘制或选中的类型。选中对象显示“当前画笔／矩形／椭圆属性”，取消选择后保留绘制面板并显示对应“新…样式”。切换类型进入新绘制，不转换已有对象；三种类型共用最近设置的颜色和取色能力，其余属性按类型展示 |

英文优先按完整单词折行，只有单词超过文本框宽度时才拆分；保留手动换行与原始空格。加粗切换到真实 Bold，再次点击恢复此前字重；直接从字体下拉选择字重会清除这次恢复记录。选择拉丁 Black 或日文字体时自动取消斜体并禁用 I，不合成伪斜体；切回支持斜体的拉丁字重后恢复 I 入口，不自动恢复此前斜体。直接选择家族/字重会清除加粗恢复记录，日文 Medium 加粗后再次点击可恢复 Medium。字体使用官方原始 WOFF2 按所选家族/字重/样式加载，不做转换或子集裁剪；资源来源及限制见[拉丁字体说明](./public/fonts/alibaba-sans/NOTICE.md)和[日文字体说明](./public/fonts/alibaba-sans-jp/NOTICE.md)。

日文字体由用户在原字体下拉中选择，不依据站点或输入文字自动替换已有字体；切换保留文案、文本框位置与宽度及其他样式，字形度量变化可使自动换行和文字高度相应变化。新文字采用当前预设，字体与字重随复制、撤销/重做、显隐/锁定和成图保留。日文自动换行避免常见句读点、闭括号及小假名落在行首，开括号不留在行尾；混排英文仍优先保留完整单词，超宽长词才拆分。手动换行、空行与原始空格保持不变；极窄文本框至少容纳不可拆开的标点组合。日文两端对齐在自动折行的非末行扩展可分开的字符间距及词间空白，括号与相邻字符、英文单词内部不额外拉开；段落末行保持左对齐，不拉伸字形或改写用户字距。预览、光标、复制及成图使用同一排版。整体0°/90°旋转方式保持不变，不将该旋转按钮描述为日文逐字竖排。

新增后 `Your text` 可以直接覆盖；未改动占位文案仍作为普通文字保留并成图。输入过程中临时清空不删除对象，结束输入时若仅剩空格、制表符或换行，则删除整段文字及背景、效果，一次撤销恢复清空前的内容和样式。Enter 换行；点击空白结束输入并取消选择。

不按“包含汉字”判断或拦截文案语言，日文汉字、假名及其他语言原文均可进入提交检测；输入法组词期间及结束后不删改文案。违禁词仅在用户确认替换后交由宿主检测，命中时保留草稿并定位问题图层。当前不实施按站点/目标语言限制文案的规则；文字能提交检测不代表已完成各语言的字体排版验收。

文字不透明度位于“更多效果”中，默认100%，支持0%–100%的数字输入和滑块实时预览，连续滑动记一步历史。该值统一控制整段文字及其背景、描边、阴影；新文字采用当前预设，复制、颜色修改和撤销／重做保留该值。0%文字仍保留图层并标记“完全透明”，可从图层选中后恢复，不拦截画布下方对象。完全透明不等于删除，其保留的非空文案仍参加提交前校验。

文字数值的悬停提示包含允许范围、单位及操作方式；回车或失焦应用，Esc 取消本次输入并保留焦点；字距为原图像素，修改字号仍保持该像素字距。未选中文字时只改新文字样式，不记历史。描边与阴影关闭后不渲染但保留参数，背景关闭也保留其颜色、留白与圆角。

字体下方五个样式按钮依次为加粗、斜体、下划线、删除线、竖版。随后两行分别为字号与对齐下拉、字距与行距，均为两列等宽、文字标签在上、控件在下。字号和字距显示 px，行距显示倍数，范围和默认值保持现有规则。下划线和删除线默认关闭，可组合开启，跟随文字字号与颜色，不单独配置颜色或粗细。输入期间隐藏“修改文字”，结束输入且仍选中文字时恢复入口。

“竖版”将选中的文字整体设置为顺时针 90°并高亮，再点回到横版 0°，文字中心位置保持不变；背景、描边、阴影和装饰一起跟随。其他角度点击也统一到 90°，一次撤销可恢复原角度。自由旋转到非 90°方向后退出竖版高亮；等价的 90°方向仍显示竖版。该按钮仅作用于单个可编辑文字，新文字始终从横版开始。横竖切换保留内部对齐选择：横版的左对齐／居中／右对齐，竖版对应上对齐／垂直居中／下对齐，下拉选项名称一起更新，两端对齐保持该选择；不改变文字框在图片中的位置。

“背景填充”展开后可单独设置背景不透明度，默认100%，支持0%–100%的数字输入和滑块；适合用半透明底色衬托清晰文字。仅影响背景，文字、描边和阴影保持原样；“更多效果”中的整体不透明度仍作用于整个文字对象，例如背景50%且整体50%时，背景实际覆盖度为25%，文字按整体50%显示。背景0%仅隐藏背景，不将文字图层标记为完全透明。关闭背景保留颜色、独立不透明度、留白和圆角，再次开启恢复；旧文字未设置时按100%显示。连续滑动记一步撤销，数字回车/失焦应用、Esc取消；新文字样式不记历史，复制、显隐/锁定、颜色取色、旋转及最终成图均保留。遮盖旧内容时应使用完全不透明的背景或遮盖层，避免旧内容透出。

文字旋转控制点沿用下述通用旋转吸附规则；“竖版”按钮仍按上述 0°／90° 切换。

第四种对齐为两端对齐，默认仍为左对齐。自动换行的非末行通过扩展词间空白及日文可分开的字符间距填满文本框，行首和行尾空白不参与扩展；手动换行视为段落结束，每段末行、单行和没有可分配间距的行保持起始对齐。保留原文字距及字形宽度，不拉伸字形。装饰、对齐和横竖方向随复制、显隐、锁定、撤销／重做及最终成图保留。

文字、画笔、矩形、椭圆及多选外框统一使用蓝色边框、白底蓝边控制点，移动时不淡化边框。控制点保持原尺寸：文字仍通过左右控制点调宽并支持旋转，画笔和图形保留原有缩放及旋转方式。选中框仅用于编辑，不进入成图。

文字工作区顶部提供“添加文字”：每次点击创建一段文字，放在当前可见图片区域中并直接输入，可拖动调整位置；如果图片已完全移出视野，先适配图片再添加。画布点击不新增文字。点击空白处结束输入并取消选择后，仍停留文字工作区，不改变属性栏的展开或收起状态。选中文字显示“当前文字属性”，未选中显示最近使用的“新文字样式”，调整只作用于下一次新增。选中其他文字回显其实际属性，选中图形展示图形属性；常用排版直接可见，描边、阴影在“更多效果”中。

未手动指定字号时，新文字默认字号按当前图片短边的 5% 取整，并限制在 8–500px，不随查看缩放改变；初始文本框宽度按图片宽度的 42% 适配，新增时沿用可见宽度 80% 的约束及排版最小宽度，避免局部放大后新文字落到视野之外。新增位置仍优先在可见区域居中并避开附近文字。已设置或继承的字号、已有文字及其手动框宽保持原样；上传换图时只重新计算系统默认字号，不覆盖手动字号和其他新文字样式。

连续添加时，新文字与附近可见文字适当错开，优先向右下方偏移；到达边缘后改用附近可容纳的位置，避免越加越远。偏移量随缩放换算，在屏幕上保持相近距离，不改变已有文字的位置。短时间误连点不重复创建，正常再次点击仍可添加；新文字立即选中并输入，提示当前文字数量，已展开的图层列表定位到新图层。大字号超出可见范围时优先让新文字中心可见，不擅自缩小字号。

### 调色

面板按**基础调节 → 滤镜 → 颜色叠加 → 重置调色**排列。基础调节和滤镜直接可见，颜色叠加默认折叠，收起时仍回显已启用的强度；所有效果只作用于当前底图，选中新增对象不改变调色的作用目标。

| 设置 | 范围与操作 |
| --- | --- |
| 亮度、对比度、饱和度 | −100～100，默认 0；分别调整明暗、明暗差异及色彩浓淡 |
| 色温 | −100～100，默认 0；负值偏冷、正值偏暖，是相对冷暖调节，不显示开尔文数值 |
| 锐化 | 0～100，默认关闭；温和增强边缘与纹理，不能恢复失焦图片 |
| 滤镜 | 无滤镜、清透、明亮、柔和、鲜明、暖阳、清冷、黑白、复古；同时仅一个滤镜生效，强度 0～100%，初始 100%。切换滤镜保留其他调节和滤镜强度；“无滤镜”只取消滤镜 |
| 颜色叠加 | 复用常用色、自定义 HEX／RGB／HSL 与图片取色；强度 0～100%，初始为 0%，选择颜色后调高强度查看效果。“取消叠加”只将叠加强度归零，保留所选颜色 |

滤镜使用当前底图的低分辨率效果缩略图，按基础调节和叠加后的图片预览 100% 滤镜强度；切换底图重新生成，过期结果不覆盖新图。处理顺序固定为基础调节、颜色叠加、滤镜，从底图源像素重新计算，不反复累计效果。黑白、复古统一归入滤镜，已移除整图模糊；本轮不提供分色 HSL、高光、阴影、绿红色调或混合模式。

滑块实时预览，松手、键盘松键或失焦时一次调整记一步历史；数字输入在回车或失焦时应用，Esc 取消草稿并保留输入焦点。自定义叠加颜色实时预览，应用记一步历史；取消、Esc 或点击外部恢复原色。取色遵循现有颜色面板规则，不修改新增对象。

已偏离默认值的数值项显示单项复位图标：基础调节及叠加强度归零，滤镜强度恢复 100%；仅恢复该项，其他参数、滤镜选择和叠加颜色保持不变，一次复位记一步历史。“重置调色”仍一次清除整套设置，可整体撤销；不删除新增内容，也不撤回已经采用的消除结果。

调色面板顶部提供“按住查看调色前”：临时查看当前底图未应用本轮调色的效果，保留已采用消除结果及可见新增内容；没有生效的调色时禁用。鼠标或空格／Enter 按住查看，松开、失焦、页面隐藏或指针取消后恢复，不修改参数、选择、历史或成图。“按住查看原图”仍以进入本次编辑时的图片为基准。

当前效果进入消除源图和最终成图；采用消除结果后将已烘焙的调色参数重置，避免重复叠加。撤销采用恢复原底图、选区和整套参数；上传新图清空调色。滤镜主要复用 Fabric.js 原生处理，色温与滤镜强度采用颜色矩阵，锐化在原生卷积基础上对齐 CPU 与 GPU 的边缘取样。

### 操作区与原图对比

左侧高亮表示所属工作区，底部“选择／平移”高亮表示鼠标操作，两者独立。矩形、椭圆松手后保持当前绘制类型和新建样式，不选中新对象、不显示控制框，可直接拖动继续画；每个图形独立成层并可逐步撤销。要修改已有图形，点击底部“选择”后点选，或直接从图层选择。“绘制”和底部“选择”此时同时高亮；在选择模式点击空白取消选择不会自动恢复绘制，再次点击类型才继续画。画笔仍支持连续多笔，选中已有笔画后可改其属性，取消选择后回到新画笔样式。新建样式仅用于下一次新增，不改变已有内容或产生历史。绘制类型入口在属性区域滚动时保持可见；面板收紧纵向留白，圆角与操作提示在较矮窗口中可向下滚动查看。

删除、隐藏或锁定导致选择解除时，也保留所属工作区。多选面板标题显示“已选 X 个图层”，正文先说明一起移动、缩放和旋转，再以次要文字提示单选后可编辑属性；不显示某个对象的属性或新建样式，删除仍使用右侧图层操作。多选不另行改变工作区高亮和面板展开状态，恢复单选后显示对象属性。选择／平移切换保留对象选择、工作区和视野；多选切到平移时改为返回选择的引导。消除工作区切到选择／平移后，显示当前模式、“返回消除笔”入口，以及已保留的消除方式、选区操作、笔刷大小（涂抹模式）和选区状态摘要，替代整组禁用控件。点击返回或左侧消除笔恢复完整设置及已完成选区，不自动消除；按住空格临时平移仍保留原消除面板。

矩形拉伸时，圆角按图片像素保持，拖动中的预览与松手结果一致；缩小时最多为当前短边的一半，同一次拖动重新放大可恢复原圆角，松手后保存最终有效值。拉伸、复制、撤销／重做与最终成图均沿用此规则。

一笔绘制、一个图形、一次移动或尺寸调整各记一步历史。已有笔画粗细、图形边框粗细／不透明度／矩形圆角和调色滑块拖动时实时预览，松手、键盘调整结束、取消指针或失焦时收尾，一次连续调整对应一次撤销。撤销／重做尽量保留仍存在且可编辑的选中对象，回显恢复后的属性；对象不再存在、隐藏或锁定时解除对应选择，保留工作区。仅切换工具、选择对象或查看图片不记录历史。

单选文字、画笔、矩形或椭圆，通过旋转控制点拖动时，接近 0°、90°、180°、270° 的小于 5° 范围内自动吸附，继续拖出范围即可自由旋转。吸附不改变对象中心，预览与松手结果一致；一次连续旋转记一步历史，复制及撤销／重做后仍可继续吸附。多选保持原有旋转方式。

绘制图形时显示深色细线与白色衬线组成的辅助轮廓，浅色和深色背景上都可定位；完成后辅助轮廓消失，保持连续绘制；主动选中已有对象时显示控制框。辅助线仅用于编辑预览，不进入成图或取色结果。画笔光标按实际粗细和缩放显示范围，始终保留深浅对比轮廓，白色画笔在白底上也能定位；范围过小时补充小十字定位点，不改变笔画粗细。矩形、椭圆按屏幕拖动距离过滤轻点和抖动，同时要求宽高均大于零；明确拖出的细长图形仍可创建，画笔点击画圆点保持可用。三种绘制类型继续共用最近设置的颜色，实心／边框不分别保存颜色。

图形不透明度只影响当前矩形或椭圆，不影响底图、文字或画笔；100% 完全不透明，降低后透出下方内容，0% 仍保留图层，可从图层列表选中恢复；图层行标记“完全透明”，新建样式为 0% 时明确提醒后续绘制不可见。空心图形内部允许点选下方内容，边线附近保留约 4 屏幕像素的点击容错；完全透明图形不拦截画布点选。切换实心／边框保留不透明度、线型和粗细，复制及撤销／重做保留这些属性。下拉收起时显示当前线型名称和示意，展开后用统一深色示意展示五种线型及当前勾选；悬停或方向键仅浏览，点击或回车／空格才应用，Esc 只关闭菜单并返回入口焦点。线段与间隔随粗细缩放，圆点使用圆形端点；旧虚线保持原效果。

画笔、矩形和椭圆绘制期间暂停滚轮缩放，松手后恢复。画笔粗细、边框粗细、图形不透明度和矩形圆角的数字输入以回车或失焦应用；Esc 恢复本次输入前的值并保留输入框焦点，取消不记历史，也不触发关闭编辑。

| 位置 | 操作 |
| --- | --- |
| 左侧工具栏 | 消除笔、绘制、文字、调色 |
| 左侧工具属性 | 初始展开消除笔设置，之后按当前工具或选中对象显示属性，可手动收起 |
| 左下角帮助 | 按需查看编辑快捷键，Esc 或关闭按钮返回编辑 |
| 左上角 | 撤销、重做、还原初始、按住查看原图，依次排列 |
| 右上角 | 上传本地图片、替换图片、关闭编辑；上传入口与主操作分隔显示 |
| 画布右下角 | 选择/平移、缩放、原图对比、图层展开/收起，按四组排列 |

右上角在上传入口前以灰色文字显示当前工作图片的宽高，例如“1280 × 800 px”，不使用按钮底色或边框。悬停说明宽高顺序及缩放不改变实际尺寸；上传新图片后按新图尺寸更新，原图对比和画布缩放不改变这一显示。窄窗口下隐藏尺寸信息，优先保留操作按钮。

左上角和画布右下角的操作以图标为主；画布与消除结果弹窗的缩放区统一依次为缩小放大镜、当前比例、放大放大镜、100% 数字和适配图标。当前比例只读、固定宽度并使用等宽数字；100% 用于查看细节，两处适配均使用四角框住中心方形的图标，悬停或键盘聚焦说明“完整显示图片并居中”。主画布到达 3% / 400% 时禁用对应缩小 / 放大按钮，并提示已到极限；结果弹窗沿用自身适配下限。悬停或键盘聚焦提供提示，模式和查看状态高亮。选择、平移互斥，点击选择可退出绘制并调整对象；平移提示保留按住空格临时拖动画布的用法。

左侧不再常驻“编辑设置”说明页，也不因取消选择退回空白“工具属性”。进入编辑时默认选中消除笔并展开设置，初始无选区，不自动消除；“开始消除”在有效选区完成前禁用。点击工具或重新选择已有对象时展开对应属性；画布上的选择、拖动等手势结束后才展开，避免操作中改变画布宽度。取消选择、删除、显隐／锁定、选择／平移切换及撤销／重做均保持属性栏原有展开或收起状态；手动收起后可再次点击工具或重新选择对象展开。面板切换保持缩放、画布中心对应的图片位置及对象选择，不修改草稿，也不改变右侧图层面板的收起状态。消除笔面板内的流程和提示保持不变。

左侧顺序保持消除笔、绘制、文字、调色。有新增内容时，切换到消除笔提示“仅消除底图内容；新增文字和绘制内容暂时隐藏，退出后恢复原有显示。”；切换到调色提示“仅调整底图；新增文字和绘制内容保持不变。”。直接进入工具，提示沿用画布上方约 5 秒自动收起的反馈，不要求确认、不移动画布；没有新增内容或重复点击当前工具不追加提示。切换取消了未完成选区时，优先保留取消提示。

绘制说明放在对应属性面板，区分新绘制、调整已有对象和返回绘制。“已撤销”“已删除”等普通反馈浮在画布上方，5 秒后自动收起，也可手动关闭；错误及检测拦截等需处理信息持续保留。提示出现、换行或关闭不改变画布尺寸，不再常驻通用顶部提示条。

通用快捷键通过左下方“帮助”查看，不再重复放在各属性面板中；取色、文字编辑、选区等必要提示仍留在对应操作旁。鼠标在帮助按钮上停留 300ms 后，在按钮右侧约 8px 处显示“操作说明与快捷键”；键盘聚焦也可查看。打开帮助立即隐藏提示，关闭按钮或 Esc 返回入口焦点后不自动重现；鼠标移开再移入或键盘重新聚焦时可再次查看。帮助弹窗中的按键不会触发画布编辑。

两处原图对比入口共用“按住查看原图”状态：左键按下立即查看，松开返回，单击不锁定。按钮聚焦后支持按住空格或 Enter；移出后松手、失焦、页面隐藏、指针取消或丢失捕获都会结束查看。同尺寸图片沿用当前缩放及位置；上传后尺寸不同则临时适配初始原图，结束时恢复工作视图及原适配状态。查看期间两处图标同步高亮，画布提示“正在查看原图 · 松开返回编辑”，不改变编辑草稿。

### 图层

- 每行展示类型图标、颜色、名称及显示/锁定按钮。文字名称跟随实际文案摘要，矩形、椭圆和画笔分别编号；底图显示实际图片缩略图。仅在隐藏、锁定或文案异常时补充状态。
- 底图固定在列表最下方，不参与普通图层的选择、排序、复制和删除。新增对象均为图片内容，无用途切换。
- 隐藏图层不参与成图；锁定只防止误编辑，不改变成图可见性。两种状态可同时存在，点击名称不会自动显示或解锁。
- 隐藏或锁定未选中的图层，保留当前选择；多选中操作其中一层，仅移除受影响的选择，其余对象的位置不变。
- 底部先显示“相对图片居中”及微调提示，详见[对象位置与微调](#对象位置与微调)；下方操作区依次提供置顶、上移一层、下移一层、置底，与复制、删除适当留白。排序针对单个可编辑图层；置顶移到全部新增内容上方，置底移到全部新增内容下方但仍在底图上方。到顶/到底时禁用对应方向的两个按钮，无选择或多选时禁用排序。排序直接生效，一次记一步撤销，保留选择与画布视野。复制针对单个选中图层；多选时显示数量并明确删除范围。删除支持撤销，不另弹确认框。
- 面板默认展开，右下角可收起并释放空间，本次编辑内记住状态；切换工具或新增内容不自动展开。面板切换保持缩放、图片中心和对象选择，对比期间切换后也能恢复编辑视图；未完成绘制、取色或载入等受限状态下暂不可切换。
- 面板展开时，新增、复制或选中对象会仅滚动列表定位，不移动画布。校验失败且返回有效图层 ID 时，提示中提供“查看问题图层”；点击后展开、定位并聚焦该行，保留隐藏/锁定状态和画布缩放。
- 消除模式下，有新增内容时图层面板提示“当前仅预览底图，新增内容已保留”，不通过改写眼睛开关实现临时预览。

### 对象位置与微调

用于将新标题、说明文字或遮盖块摆到合适位置。图层面板底部提供“相对图片居中”，下方显示方向键微调提示；完整快捷键说明见左下角“帮助”。

| 操作 | 作用范围与结果 |
| --- | --- |
| 水平居中 | 选中单个文字、矩形、椭圆或画笔，将其外框中心移到当前图片的水平中心，只改左右位置 |
| 垂直居中 | 选中单个新增对象，将其外框中心移到当前图片的垂直中心，只改上下位置 |
| 方向键微调 | 每次移动 1 个图片像素；Shift＋方向键移动 10 个图片像素，缩放不改变步长；多选时整体移动并保持对象间相对位置 |

居中以当前工作图片的完整宽高为准，上传后使用新图片尺寸，与画布缩放、平移或当前可见区域无关。它移动整个对象，不改变文案、文字框内对齐、尺寸、旋转角度、样式或图层顺序，也不改变画布视野。文字输入中点击居中会先结束输入；空文字按现有规则删除后不执行移动。

每次实际居中可单步撤销，重复居中不增加历史。方向键长按实时预览，全部方向键松开、焦点离开或切换操作时合为一步历史；切换对象后的残留重复按键不移动新对象。撤销／重做保留仍可编辑的对象选择、画布视野及面板状态。

居中仅用于单个可编辑新增对象，无选择、多选、平移或受限状态时禁用。微调在画布、图层选择或居中按钮获得键盘操作时生效；文字输入、数字框、下拉菜单、平移（含按住空格）、原图对比、确认弹窗和请求处理中不会触发位置微调，Ctrl／Alt／Meta＋方向键不作为移动快捷键。

底图、隐藏及锁定对象不参与位置调整，完全透明但仍可编辑的新增对象可以从图层选中后调整。位置调整沿用画布自由移动范围，不强制将越界对象收回图片内。当前不包含多对象互相对齐、等间距分布或拖动吸附线，后续新增须另行确认。

### 上传、替换与确认

“上传本地图片”仅载入编辑草稿，不立即替换任务图片；“替换图片”才通过宿主检测并保存编辑结果，成功后返回审核。

当前上传原文件仅在浏览器内校验；宿主替换契约接收最终合成 JPG，不包含原始上传文件。M-37218 要求的后端原文件校验仍需在 ERP 接入时补齐文件传递、校验回执及草稿关联，不能用最终成图校验代替；本仓库尚未实现该接入。

上传成功后默认选中消除笔，左侧已展开时显示消除设置，手动收起时保持收起；取消选择、取消载入确认或上传失败，保留原来的工具与面板状态。载入图片不会自动开始消除。

| 操作 | 确认与恢复规则 |
| --- | --- |
| 替换图片 | 在原确认弹窗内完整展示最终成图，并提醒替换后不可恢复；预览加载成功后才允许确认，用户确认后才开始检测和保存，提交复用同一份 JPG；编辑器不提供已提交替换的撤销入口 |
| 还原初始 | 提醒将恢复初始原图；确认后执行，可通过撤销恢复还原前的草稿 |
| 上传、关闭、切换编辑图片 | 存在未保存修改、未完成选区或待处理/待采用结果时提醒；取消保留当前草稿 |

上述操作统一使用页面内确认弹窗：默认聚焦取消，Esc 和关闭按钮等同取消，点击遮罩不关闭；等待确认时锁定编辑，重复确认只执行一次，晚到的消除结果不会抢占弹窗。浏览器刷新或关闭标签页仍使用原生离开提醒，结果预览和提交进度弹窗保留各自规则。

替换预览包含当前底图效果、可见文字及绘制内容，锁定图层仍按原显隐成图；在消除工作区中也展示完整结果，排除选区和选中辅助线。预览生成或加载失败时阻止确认，可重新生成或返回编辑；取消、关闭或新一轮确认后，旧预览不恢复或覆盖当前内容。预览只在本地合成，确认前不调用文案检测或保存。

### 消除选区

进入消除选区时固定显示并提交当前工作底图，后加文字和图形不参与消除。这个隔离**不修改已保存的图层显隐属性**；退出工具后恢复原有显示。

四种选区的操作约定：

- 涂抹：滑块或数值输入调整大小，范围为原图 4–300px；数值回车或失焦生效，Esc 取消本次输入，空值恢复原值，越界值自动限制到范围内。一笔内大小固定。光标圈表示笔刷的实际覆盖范围。
- 框选：拖动中按住空格可移动选框，松开空格后继续调整大小；移动限制在图片内。未开始框选时，空格仍用于平移画布。
- 圈选：拖动时只显示轨迹与首尾连接预览，松手后闭合并填充；保留图外拖动与松手位置，完整路径按图片边界裁切，预览和导出使用相同路径。交叉路径按图内实际填充面积判断是否有效，图外面积不计入。
- 多边形套索：至少三个顶点后才启用起点闭合吸附，吸附范围随选区尺寸和邻近顶点距离缩小，避免小选区提前闭合；顶部撤销、Ctrl+Z、退格均可撤销上一点，Enter 完成，Esc 取消；草稿期间禁用重做和初始对比。按钮获得焦点时，回车和空格优先操作按钮，不触发画布快捷键。
- 消除笔面板内的“按住隐藏选区”在按住时显示“松开显示选区”，临时隐藏选区遮罩，保留当前工作底图；松手、移出后松手、窗口失焦或操作取消后恢复，不清空选区。按钮获得焦点时也支持按住空格或 Enter；无有效选区或选区尚未完成时禁用。它与两处“按住查看原图”入口不同，后者查看初始原图。
- 不额外维护添加/减去次数，选区历史统一记录操作。有效选区按与导出相同的二值阈值检查最终像素；完全减空后禁用开始消除，撤销后重新判断。

选区收尾与异常操作：

- 涂抹、框选、圈选完成前采集松手位置，只有发起操作的左键松开才完成选区；不同指针和其他鼠标键不能提前结束。操作取消、窗口失焦只取消草稿，不清除完成的选区。
- 涂抹离图时画至边界后暂停，回图后从边界继续，但不跨图外空白连接、不沿边缘追踪鼠标。分段轨迹仍是一笔，预览、撤销、重做和导出 Mask 使用相同断点。
- 重复点击当前工具或当前添加/减去模式不改变草稿；真正切换时取消未完成部分并提示，已完成选区保留。
- “清空选区”清除本轮选区并回到添加模式，保留工具、笔刷大小；可通过顶部撤销恢复。减空后自动回到添加模式；无选区时不能减选。
- 未改变已有遮罩的减选不新增历史。判断实际透明度变化，保留可能影响后续编辑的细微边缘变化。
- 已完成选区统一通过顶部撤销/重做及对应快捷键操作；面板仅在套索草稿期间提供“撤销上一点”，不再提供含义不同的“撤销上一步”。
- 轨迹、笔刷圈及套索节点增加浅色对比描边；无效小选区提示放大图片后重选。

面板从上到下为：四种选区类型、当前类型提示、添加/减去、涂抹时的笔刷大小、按住隐藏选区、清空选区和开始消除。框选明确提示“拖动框选；松手前按住空格可移动选框”；圈选说明松手自动闭合。套索提示随顶点数量更新，不足三点时引导继续加点，至少三点时提示点击起点或按 Enter 闭合；仅草稿期间显示“撤销上一点”。减去模式额外提示从已有选区中减去无需消除的区域；无选区时说明需先选择区域，未完成选区时不能提交。

有新增文字或绘制对象时，在面板轻提示“当前仅显示底图，新增文字和绘制内容已保留”，无新增内容或正在对比初始图片时不显示。普通选区完成不重复提示；取消、无效减选等反馈浮在画布上方，5 秒后收起，不改变画布尺寸。失败及服务未接入时持续显示原因并说明图片、选区已保留，直到用户关闭提示或后续操作更新。处理期间按实际阶段显示“正在准备图片和选区…”、“正在等待消除结果…”和“正在生成对比预览…”，保留“取消等待”。服务等待达到 10 秒后显示实际已等待秒数；结果返回、取消或结束后停止计时，新请求重新计时，不推算进度、排队位置或剩余时间。取消后保留原图片和选区。

### 消除结果预览与采用

1. 消除笔固定提交当前工作底图和同尺寸 Mask；不合并后加文字和图形。
2. 提交时固定文档 ID、修订号及输入快照；同一文档只运行一个消除请求。
3. 请求期间暂时锁定内容编辑，允许取消等待或确认后上传替换图片。新图片校验、载入成功才清空旧草稿并隔离旧请求；上传失败保留旧草稿。取消等待不承诺后端停止计费或生成。
4. 返回单个结果后先展示消除前/消除后，不立即覆盖文档；对比两侧保留相同的可见新增内容，操作规则见下表。使用消除结果仅更新编辑草稿，仍须点击右上角“替换图片”才保存到任务。
5. 使用结果时只替换底图，后加文字和图形保留可编辑，隐藏图层也保留。
6. 采用时清除本次选区，并重置已烘焙进源图片的调色参数；整体操作可撤销。采用后继续停留在消除笔，保留选区工具和笔刷大小，回到添加模式，可直接开始下一轮。
7. 放弃／失败保留原内容与选区。旧文档、旧修订或已取消的结果不能写回当前文档。

| 预览操作 | 行为 |
| --- | --- |
| 缩放和平移 | 两侧共享查看位置，在任意一侧操作即同步；提供缩小、放大、100% 和适配，滚轮以指针位置缩放，视图聚焦后可用方向键平移 |
| 初始视图 | 默认适配且不放大小图，最大 400%；查看方式不改变实际成图或尺寸 |
| 消除区域 | 圆形靶心图标加“消除区域”文字（可访问名称“查看本次消除区域”），放在通用缩放组后并用分隔线区分；点击将两侧同步定位到本轮最终有效选区及适量周边。按实际二值 Mask 的白色像素计算，包含减选结果和全部分散区域，最多放大至 400%。只改变查看位置，不扩大提交选区；仍可一键适配整图 |
| 预览生成失败 | 服务返回的有效同尺寸结果保留；弹窗提供“重新生成预览”，不重新请求消除。重试期间禁用重复生成及采用，仍可明确放弃结果；取消、换图、关闭或卸载后，晚到预览不能恢复或覆盖当前结果 |
| 预览加载失败 | 两张图均加载完成后才可采用；“重新加载预览”沿用已有图片，不重新发起消除 |
| 采用失败 | 在弹窗内提示，保留图片、选区和待采用结果，可“重试使用结果” |
| 放弃 | 仅点击“放弃结果”才放弃，Esc 不关闭结果弹窗；画布中的 Esc 仍可取消未完成绘制 |

当前版本只接受**与输入同宽同高**的结果。尺寸不一致时拒绝采用，不擅自缩放或重新定位已有图层。
选区外像素是否保持、商品一致性、生成质量仍属于前后端联调验收范围，前端不会据此宣称模型只修改了选区。

## 消除接口

适配器见 [src/lib/eraseApi.ts](./src/lib/eraseApi.ts)。以下是**当前前端适配器约定，尚需后端确认和实现**，不是已上线接口说明。开始调试前请阅读[联调与接入约定](#算法联调与-erp-接入约定)，沿用已确认的消除笔交互基线。

### 环境配置

本项目提供本地生产接口转发入口。拉取项目最新代码后，按以下步骤配置：

1. 联系算法同事获取真实消除服务的 **Username 和 Key**。
2. 首次配置时，将项目根目录的 `.env.production-test.local.example` 复制为 `.env.production-test.local`；已有本地配置则直接编辑，不覆盖。将 Username 填入 `LAMA_USERNAME`，将 Key 填入 `LAMA_API_KEY`。模板中两项默认留空，实际凭据仅保存在被 Git 忽略的本地文件中，不写入文档或提交到 Git。不要改成 `VITE_` 前缀。值含 `$` 时按 Vite dotenv 规则写成 `\$`。
3. 在同一 4180 端口将演示服务切换为 `npm run dev:production-test`，访问 `http://127.0.0.1:4180/`。填写或更改凭据后重启该命令；凭据有效且服务可访问时，即可使用真实消除笔。普通 `npm run dev` 仍使用普通环境配置。
4. 消除笔通过 `VITE_ERASER_API_URL=/api/eraser` 调用本机 Node 转发层；它从服务端配置读取凭据，向 `http://person-detector.zhcxkj.com/api/lama/inpaint` 发送 `image`、`mask` 两个文件，移除 metadata，添加 Basic Auth 和请求 ID，再转发 JPG 或错误响应。能力服务地址及默认 180 秒总超时在 `.env.production-test` 配置，必要时可在忽略的本地文件覆盖。

生产测试转发层仅允许本机同源调用，不是公开部署的业务后端。凭据不会进入浏览器请求头或前端构建；GitHub Pages 只托管静态文件，不能运行此转发层。测试构建可执行 `npm run build:production-test` 后运行 `npm run preview:production-test`。本地转发当前使用文档给出的 HTTP 服务地址。

未填凭据时，消除笔会提示先填写本地账号和密钥，不向能力服务发请求；错误凭据显示鉴权失败。取消等待会断开转发请求，但不保证已开始的能力服务 GPU 推理停止。不自动重试，不落盘保存用户输入或输出图片。当前已验证本地转发和受控响应，真实生产消除仍需填写凭据后联调。

正常响应结束不再触发上游取消；浏览器异常断开及等待超时仍中止转发等待。总超时以 HTTP 504 和 `LAMA_REQUEST_TIMEOUT` 返回，与连接失败区分；前端说明后台可能仍在处理，超时不表示能力服务已停止。

普通业务后端接入继续使用以下配置：

```dotenv
VITE_ERASER_API_URL=
VITE_DEFAULT_IMAGE_URL=
```

在 `.env.local` 中将 `VITE_ERASER_API_URL` 配置为**业务后端**的消除接口地址，调用链为：前端 → 业务后端 → 图片消除能力服务。尚未提供地址时保持留空，页面提示“消除服务尚未接入，图片和选区已保留”，不模拟成功。修改配置后重启开发服务；部署时需重新构建。`VITE_DEFAULT_IMAGE_URL` 为独立预览的默认图片地址。跨域图片和接口需要正确的 CORS 配置。

能力服务的 Basic Auth 凭据仅由业务后端管理，不放入前端代码或环境变量。已移除原有直连能力服务的开发代理和前端鉴权配置。业务系统自身的鉴权、权限与审核回流需在实际接入时定义。

### 输入范围与请求

`editorRole` 区分文字、图形、绘制等对象类型，`editorPurpose` 仅区分底图 `base` 和新增内容 `content`。

| 对象 | 最终 JPG | 消除源图片 |
| --- | --- | --- |
| 当前底图（包含当前调色效果） | 参与 | 参与 |
| 新增文字、图形、自由绘制 | 可见时参与 | 不参与，采用消除结果后保持独立可编辑 |
| 消除选区 Mask | 不参与 | 作为独立 `mask.png` 提交 |

消除接口使用 `POST multipart/form-data`：

不要手动设置 multipart 的 `Content-Type`，浏览器会自动生成 boundary。业务后端接收以下三个字段，调用能力服务时负责筛选，只发送 `image` 和 `mask`。

| 能力 | 环境变量 | 字段 |
| --- | --- | --- |
| 消除 | `VITE_ERASER_API_URL` | `image`、`mask`、`metadata` |

- `image`：从当前工作底图生成的 JPEG 文件 `image.jpg`，包含当前调色效果，使用当前图片物理尺寸和白色背景；不是固定重传初始原图，也不合并新增图层。
- `mask`：`mask.png`，`Content-Type: image/png`，与源图同尺寸，PNG bit depth 为 8、color type 为 0（单通道灰度），无 alpha 通道、无 `tRNS` 块。保留覆盖度阈值 128，二值化后黑色像素为 `0`（保留）、白色为 `255`（消除）。减选通过几何合成后统一二值化。选区按用户实际涂抹、框选或圈定的范围合成，不额外向外扩大。
- `metadata`：保留版本、消除操作、底图范围、尺寸、前端会话标识和坐标相关字段，并携带本轮 `requestId` 关联使用记录，示例见下；业务后端不要将此字段转发给能力服务。前端 ID 不是审核系统任务 ID 或鉴权凭证。

选区仍使用现有 Canvas 绘制与加减规则；`exportMask` 读回像素后，将缓冲转移给专用 Worker。Worker 沿用 `binaryPixels`，从已经二值化的像素原地提取单通道，使用轻量 PNG 封装和浏览器 `CompressionStream("deflate")` 直接编码；不经过 RGBA PNG 中转，不调用 Canvas PNG 编码器。需要支持模块 Worker 和 CompressionStream 的浏览器。

Worker 在提取灰度像素时同步计算最终白色像素的外接范围，供结果预览定位使用，不另建整图缓冲。该范围使用图片像素坐标，仅保留在当前待采用结果中，不进入消除请求 metadata，也不改变 Mask。

像素循环、压缩与校验码在 Worker 内执行，按 64 行分批送入压缩流，不分配第二份完整灰度图或未压缩扫描线图；Canvas 读回后立即释放，Worker 在成功、失败或任务取消时均销毁。`exportMask` 接收任务 AbortSignal，编码期间取消、换图、确认关闭或卸载会终止 Worker、清理回调并退出任务；旧任务不再继续渲染 JPEG 或发送请求。绘制及 Canvas 读回仍在主线程。返回值仍为 Blob，原图 JPEG、请求字段、metadata 和结果处理机制不变。

灰度编码检查与性能入口为 `/tests/mask-png.html`，复用的正确性检查也包含在 `/tests/browser.html` 中。已落盘的样例、独立解码结果及性能记录见[灰度蒙版验证报告](./docs/verification/mask-png-20260908/report.md)。体积与耗时取决于选区复杂度、浏览器和设备，不能将样例结果直接视为线上收益。

{

  "mode": "erase",

### 响应与联调

当前成功响应约定为 `image/jpeg` 图片二进制，沿用图片载入、同尺寸检查和预览确认流程。

支持的返回方式：图片 Blob，或 JSON 中的 `url`、`imageUrl`、`resultUrl`、`image`、`base64`，这些字段也可以放在 `data` 下。支持 base64 Data URL、纯 base64；结果 URL 支持 HTTP(S)，相对路径以接口地址解析。当前只取一个结果，不包含多候选或消除任务轮询协议。

联调需核对请求字段、鉴权/CORS、返回图片可读取性、同尺寸要求、失败与取消后的重试，以及选区外像素和商品一致性。接口有响应不等于上述验收已完成。`metadata` 中的前端会话标识不能替代宿主业务 ID 或鉴权。

错误解析统一在 `src/lib/eraseApi.ts` 中处理，支持能力服务的 `detail.code`（如 `INVALID_MASK_FORMAT`），以及业务后端的顶层 `code` / `errorCode`、`error` / `data` / `detail` 嵌套包装。优先使用可识别的具体错误码；其余错误码别名仍需按真实业务后端契约核对。

| 错误情况 | 提示 |
| --- | --- |
| 文件或像素尺寸超限 | 图片过大，请调整后重试 |
| 蒙版格式、尺寸或选区无效 | 选区数据无效，请重新选择 |
| 服务繁忙、排队超限 | 服务繁忙，请稍后重试 |
| 排队等待超时 | 排队等待超时，请稍后重试 |
| 处理或转发等待超时 | 等待消除结果超时，后台可能仍在处理，请稍后重试 |
| 服务未就绪 | 消除服务暂不可用，请稍后重试 |
| 网络异常 | 无法连接消除服务，请稍后重试 |
| 转发返回无效结果图片 | 消除服务返回的图片无效，请稍后重试 |

非 JSON、未知错误或错误体解析失败时，按 HTTP 413 / 429 / 408、504 / 502、503 分别兜底为过大 / 繁忙 / 等待超时 / 暂不可用；HTTP 401 提示鉴权失败，其余显示“消除请求失败，请稍后重试”，不展示原始响应内容。`LAMA_INPAINT_QUEUE_TIMEOUT` 表示排队超时，`LAMA_REQUEST_TIMEOUT` 表示转发等待超时，`LAMA_CONNECTION_FAILED` 表示连接失败，`LAMA_INVALID_RESPONSE` 表示结果无效。失败保留图片和选区，不自动重试；用户取消等待后，旧请求成功或失败均不覆盖当前状态。

本地受控响应测试不代表真实接口联调完成；业务后端地址尚未提供时，真实接口联调仍未完成。

### 消除使用记录

已提供轻量前端埋点，用于观察使用量、请求成功情况、等待耗时及结果采用情况。记录入口见 [`src/telemetry.ts`](./src/telemetry.ts) 和宿主可选的 `integration.telemetry`。当前没有埋点接收后端、集中存储或统计报表；接好前端入口不代表已经上线集中统计。

| 事件 | 记录时机与口径 |
| --- | --- |
| `erase_started` | 有效操作通过检查，开始准备图片与选区；空选区、服务地址未配置等未开始处理的点击不计入 |
| `erase_request_started` | 准备完成，实际调用消除请求；用于统计请求次数 |

| `erase_preview_failed` | 区分对比图生成失败与图片加载失败，记录尝试次数；不归为算法请求失败 |
| `erase_preview_shown` | 两张对比图都加载成功、预览可查看时记录，每轮仅一次；耗时从本轮开始到首次可看，包含准备、请求、预览及重试等待 |
| `erase_apply_failed` | 结果载入编辑草稿失败，仍可重试；不记已采用 |
| `erase_cancelled` | 取消正在进行的准备、等待或预览，区分主动取消与换图、关闭等原因 |
| `erase_decision` | 成功采用记 `accepted`；明确点击放弃记 `discarded`；换图、上传、关闭、卸载或实际离开时尚未选择的有效结果记 `no_decision`，同时记录是否曾成功展示 |

每条记录包含 `schemaVersion`、唯一 `eventId`、本轮 `requestId`、发生时间、环境、图片宽高、来源、`documentId`、`imageSessionId` 和修订号；接入宿主时附带 `taskId` / `imageId`。同一载入图片的多轮消除共用 `imageSessionId`，成功换图或上传后更新；没有宿主业务 ID 时，只能统计会话内载入的图片，不能据此跨会话识别同一商品图。

服务实际返回时才记录 `serverRequestId`、`algorithmVersion`、排队／推理／服务总耗时，分别读取 `X-Request-Id`、`X-Algorithm-Version`、`X-Queue-Wait-Ms`、`X-Inference-Ms`、`X-Total-Ms`；缺失字段留空，不假定版本或将缺失耗时当成 0。新增版本响应头仍需算法同事对接；跨域业务接口须允许前端读取这些响应头。本地生产测试转发层将前端 `requestId` 用于上游 `X-Request-Id`，并转回服务响应标识和版本，向算法服务仍仅提交 `image`、`mask`。

统计时按 `eventId` 去重、按 `requestId` 关联；预览重试不增加消除请求次数，采用后的内部清理、撤销和重做不重复计算采用或放弃。可用“已展示且明确采用的结果数 ÷ 已展示且明确采用或放弃的结果数”观察决策中的采用率，并单列未选择及缺失决策；采用率是使用信号，不等于满意度、最终保存率或算法画质得分。成功率需单列取消和未结束请求；同图再次消除不直接视为前次失败。

宿主接入示例（在初始化编辑器前构造一次稳定适配器；`receive` 由宿主实现实际接收）：

```ts
import type { EditorIntegration, EraseTelemetryEvent } from "./src/integration";

function withEraseTelemetry(
  adapter: EditorIntegration,
  receive: (event: EraseTelemetryEvent) => void | Promise<void>,
): EditorIntegration {
  return { ...adapter, telemetry: { environment: "test", onEvent: receive } };
}
```

正式业务接收时将 `environment` 设为 `production`；未覆盖时按构建模式区分 `development`、`local-test`、`demo`、`production`。宿主接收函数应快速返回，自行负责发送、鉴权、持久化、去重及统计；编辑器不等待接收完成，不自动重试，接收异常不改变编辑流程或显示错误。页面离开记录尽力发送，浏览器崩溃或强制关闭可能丢失；缺失决策保留为未知，不能补算为放弃。取消原生离开确认、进入可恢复的页面缓存不提前结束本轮记录。

本地 `npm run dev` / `npm run dev:production-test` 可在浏览器控制台执行 `window.pixelweaveTelemetry.read()` 查看最近 200 条记录，执行 `.clear()` 清空。仅保留页面内存，刷新即清空；生产构建不提供此调试入口，也不自动上传或持久化。没有宿主接收函数时，正式构建不会保存记录。记录不包含图片、图片 URL、Mask、文字内容、账号、Key 或原始错误信息；样本留存与人工画质评价另行确认。

### 新增文案违禁词检测

违禁词检测只在用户点击“替换图片”并完成现有确认后触发；输入、停顿、结束编辑、改字号/颜色不发请求，也不增加独立检测按钮。检查全部保留的非空新增文字，包括隐藏、锁定和完全透明图层；不把底图文字送入此接口。无新增文案时跳过，成图检查仍由 `replace` 承担。

- 命中时阻止保存，保留草稿；画布顶部仅显示“X 个文字图层的文案需修改”，不汇总具体词。当前文字属性区显示“包含违禁词：XXX、YYY，请修改后再次替换。”，所有对应图层标记“文案需修改”。“查看问题图层”依次展开并定位多个问题，不自动显示或解锁图层。定位到未选中的问题图层时，在该行下方显示“本图层违禁词”及显示/解锁/选择后的编辑引导，保留原有选择；选中后具体词转由左侧当前文字属性展示，右侧详情收起。手动选择图层或在画布上切换选择时结束旧详情查看；已收起的详情不会因离开该图层而重新出现，只有再次点击“查看问题图层”定位到不可编辑目标时才重新展开，不重置问题定位的循环顺序。
- 修改文字内容后旧提示失效，其他图层的问题保留；改样式或位置不清除问题。撤销恢复同一图层原文案时仍展示已知问题。检测提示不写入历史或最终图片。
- 修改后由用户再次点击替换并确认成图，重新检测全部最新文案；全部通过才提交已确认的成图并继续图片检测和保存流程。不自动复检问题文字。
- 请求失败、15秒超时或回执异常时不保存，解锁并保留草稿，用户可再次替换重试；超时请求或已卸载会话的晚到结果不再生效。

若后端接口接收一段文字并返回违禁词数组，宿主可以使用 `createTextValidator`：

```ts
import { createTextValidator } from "./src/integration";

// checkText 由宿主实现：处理真实地址、鉴权和响应字段，仅成功时返回 string[]。
// [] 表示检测通过；接口失败必须抛错，不能用 [] 代替失败。
const validateTexts = createTextValidator(checkText);
```

适配器对每段文案调用 `checkText(text)`，前端保留图层对应关系，后端无需接收/返回图层 ID。同次提交中内容完全相同的文案共用一次请求，命中后标记所有对应图层；不按违禁词反查文本来猜测图层。不跨提交缓存通过结果。

宿主已有批量接口时，也可直接实现 `validateTexts`：通过返回 `{ passed: true }`，命中返回 `{ passed: false, message, issues: [{ objectId, words: ["word1", "word2"] }] }`。`objectId` 必须来自本次入参，`words` 为非空字符串数组。多个图层/多个词均支持；保留原 `{ passed: false, message, objectId? }` 兼容。真实请求地址、鉴权和原始响应字段尚待提供，本次仅完成前端契约与模拟检查，不能视为真实接口已联调。

替换确认弹窗先生成并完整展示最终 JPG；确认后锁定编辑、检查新增文案，再校验已确认的同一份 JPG 的实际编码和尺寸并提交，不重新合成另一张图片。仅选区变化不能提交，消除处理中或结果尚未采用时也不能提交。上传来源为 `upload`，不携带原图的 `baseRecordId`，但保留本次编辑的任务和图片目标；在线编辑来源为 `online`。

来源跟随实际底图与历史快照：上传后还原初始会恢复系统图片及 `online`，未再修改时不能提交；继续修改后使用原系统底图关联。撤销还原则恢复之前的底图与来源。不能仅以本次是否执行过上传判断 `source`。

宿主的保存流程须保证：保留原始图片与历史成功替换记录，只更新最新生效图片；新图进入待审核状态，旧图上的评分和审核结论不能直接沿用。真实检查规则、标识方式、保存接口和审核字段以业务系统为准，本仓库没有实现这些服务。

### 替换处理进度与结果

确认后在一个弹窗内显示“新增文案 → 图片检测 → 保存图片 → 返回审核”，区分进行中、已完成和尚未开始。无新增文案时标明“无需检查”；图片检测内按真实回报显示人物检测、识别文字、检查图中文字或准备保存信息。仅有明确保存成功回执才进入返回审核。

`progress` 支持 `ReplacementProgress`，在实际阶段开始时调用：

```ts
progress({ stage: "person" }); // 开始人物检测
progress({ stage: "ocr" }); // 人物检测完成，开始 OCR
progress({ stage: "image_text" }); // OCR 返回文字，开始检查图中文字
progress({ stage: "marking" }); // 必要检查完成，准备保存信息
progress({ stage: "saving" }); // 必要打标及文件校验完成，开始保存
```

可附带简短的用户可读 `message`，不传时使用对应默认说明。OCR 明确无文字可跳过 `image_text`。宿主从真实处理状态获取进展，后端通知或查询的传输方式由接入方确定；不能用定时器模拟阶段完成。回报只更新展示，不代替检测结果和保存回执。前端忽略无效、倒退及本次请求结束后的晚到阶段。

兼容旧的 `progress("正在处理…")`：仅更新说明，不从文字猜测阶段。未回报阶段时保持通用的“正在等待图片检测与替换结果”，不自动推进保存。处理中达到 10 秒后显示实际已等待秒数，不显示百分比、预计完成时间或倒计时；进入查询及审核回流时重新计时。结果未知或刷新失败等待用户操作时不显示处理计时。

替换结果约定：

- `succeeded` 必须带已持久化的 `recordId`；`failed` 必须表示明确失败且后续不会再产生该次保存效果；尚不确定时返回 `pending`。
- `replace` 发出后发生网络异常，前端按结果未知处理，保留同一个 `submissionId`，锁定编辑、上传、关闭和重复提交。弹窗显示“替换结果待确认”，不再显示未确认完成的流程步骤；用户点击“查询替换结果”调用查询接口，查询期间不重复执行。宿主须按该 ID 保证幂等及可靠查询，不能把超时直接解释为保存失败。
- 检查或明确保存失败后，解锁并保留草稿；返回有效 `objectId` 时，对应文字图层标记“文案需修改”，可通过“查看问题图层”展开并定位，隐藏/锁定属性保留。
- 保存成功但审核刷新失败时，保留成功记录，只重试返回审核，不再次保存。浏览器刷新、关闭标签页或宿主卸载不等于取消后端保存；宿主负责继续追踪已发出的提交，重新进入时按后台当前生效记录展示。跨页面关联在途提交与结果查询须在接入时落实，不能依赖编辑器内存或忽略回调来取消后端保存，也不代表支持未保存草稿恢复。

## 会话与限制

- 历史只保存对象和图片资源 ID，不在每一步复制图片 Base64。仅选区变化时，撤销/重做直接恢复选区，复用现有图片及图层对象；涉及图片、对象、调色或尺寸变化时完整恢复，历史顺序保持一致。
- 最多 50 个历史快照，并按 256 MiB 的资源/快照估算预算回收较旧历史；初始图片、当前文档、待采用结果和仍在处理的请求资源保持引用。
- 上述是历史缓存预算，不是浏览器进程内存硬上限；解码、渲染、合成还会产生临时内存。上传不额外设置文件大小、像素或尺寸上限，也不自动压缩尺寸；实际仍受浏览器解码、画布和内存能力约束，载入失败保留当前草稿。
- 上传需同时满足 JPG/JPEG 后缀、JPEG 文件特征和实际可解码；不依赖 MIME 声明判断。取消选择、取消放弃确认、格式错误或载入失败均保留旧草稿。成功才清空旧图层、调色和选区并重置当前撤销历史。
- “按住查看原图”及“还原初始”始终指进入本次编辑时的图片，上传后也不改变该基准。还原需确认，且可以撤销回还原前的草稿。
- 有草稿、生成任务或待采用结果时，关闭编辑需确认；页面关闭/刷新会提醒未保留的编辑。替换处理中或结果未知时不能从编辑器关闭。
- **尚未实现跨会话草稿或可编辑工程保存**。不要把本地撤销历史理解为审核系统的持久化替换记录；后者由接入的宿主服务负责。

当前不包含整体/局部指令改图（后续另行规划）、箭头与编号、OCR 去字与文字图层重建、自动对象/Logo 识别、图片翻译、裁剪/改尺寸/扩图、专业生成式图层及多候选消除结果。

核心回归包括：

- 消除请求：取消后重试、旧文档/旧修订隔离、换图后的迟到响应，以及 HTTP 错误、非图片、损坏图片、尺寸不符和 JSON 缺少图片时的选区保留。
- 编辑与导出：隐藏图层排除、文字背景、图形/笔画属性、克隆及撤销后的像素、缩放取色、上传伪装格式/损坏文件和初始原图基准。
- 宿主替换：文案拦截、结果未知时锁定、沿用同一提交 ID 查询、旧进度隔离，以及保存成功后只重试审核回流。

视觉修改还需实际检查紧凑布局、文字截断、点击范围、提示裁切和键盘操作。测试页中的 4K 连续选区耗时仅反映当前环境，不代表所有设备；真实联调另行验收消除质量、检测失败、人物标识、持久化记录、审核状态/位置及幂等保存。
