# 自研图像编辑能力

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

PixelWeave Studio（仓库名 `pixelweave-studio`）是面向商品图片审核的轻量二改前端，使用 React、Fabric.js、TypeScript 和 Vite，版本见 [package.json](./package.json)。

本文说明当前能力、操作与系统接入方式。修改项目前请先阅读 [AGENTS.md](./AGENTS.md)，其中记录协作方式、已确认的交互基线和验证要求。

## 项目定位与状态

画布上始终只有一张当前底图，后加文字、图形和画笔保持独立可编辑。独立页面用于开发与预览；接入审核系统后，由宿主提供业务图片、检测、保存和审核回流。

| 范围 | 当前状态 |
| --- | --- |
| 前端编辑 | 消除选区、文字、绘制、调色、图层、撤销/重做、JPG 上传及提交状态管理已实现 |
| 消除笔交互 | 前端交互已确认定稿；支持结果预览、采用、放弃和异常恢复，真实消除效果仍待后端联调 |
| 绘制交互 | 已完成本轮优化并形成当前稳定基线；连续绘制、对象属性、颜色取色、拉伸与圆角、历史恢复及成图规则见下文 |
| 文字 | 已有功能及部分已确认规则，整体体验尚未定稿 |
| 调色 | 五项基础调节、颜色叠加及八种滤镜已实现，具体范围与操作见下文 |
| 消除服务 | 已有图片与 Mask 请求适配器；配置接口地址不代表完成兼容性或效果验收 |
| 宿主系统 | 已有接入契约；真实文案/成图检测、人物识别、标识写入、持久化保存及审核回流仍需接入 |

未配置消除服务时，点击“开始消除”保留图片和选区并提示，不用白色覆盖模拟 AI 结果。未接入替换服务时保留草稿，不显示虚假的保存成功。

消除笔、绘制和调色的稳定基线后续默认保留，用户明确提出的调整仍可实施。继续完善文字或其他模块时，先阅读当前代码与 [AGENTS.md](./AGENTS.md)，按已确认范围修改；涉及共享控件、画布或历史时验证其他模块的相关流程。

当前范围包含调色，与旧 M-37218 PRD 的范围存在差异。PRD 用于参考业务思路，现状以最新代码和已确认规则为准；正式 PRD 未在本仓库修改。

## 快速启动

需要 Node.js 和 npm。当前 Vite 的 Node.js 要求为 `^20.19.0 || >=22.12.0`（20.x 需至少 20.19.0，或使用 22.12.0 及以上版本）；依赖安装以 `package-lock.json` 为准。

在项目根目录执行，以下为 Windows PowerShell 命令：

```powershell
npm ci
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
npm run dev
```

其他 shell 可用 `[ -f .env ] || cp .env.example .env` 完成配置文件初始化；已有 `.env` 不要覆盖。不配置后端也可预览编辑界面，配置项见[消除接口](#消除接口)。

默认地址为 `http://127.0.0.1:4175/`。端口占用时开发服务可能使用其他端口，以启动输出为准。支持 `?image=https://...` 指定初始图片，包含特殊字符的图片 URL 应编码；远程图片需要允许跨域读取。

### 在线演示与部署

Pages 首次启用并部署成功后，演示地址为 [ziziran97.github.io/pixelweave-studio](https://ziziran97.github.io/pixelweave-studio/)。演示站用于前端体验与评审，构建时将消除接口和默认远程图片地址置空，不接入真实任务保存服务；本地上传图片用于当前浏览器中的编辑。

自动部署配置见 [.github/workflows/deploy-pages.yml](./.github/workflows/deploy-pages.yml)。推送到 `main` 或手动运行 `Deploy GitHub Pages` 时，使用 Node.js 24 安装依赖、运行单元测试、构建并部署 `dist`。仅该部署构建设置 `--base=/pixelweave-studio/`（根据仓库名生成），本地开发和宿主接入的默认路径保持不变。

首次启用需要有 Pages 设置权限的仓库管理员或维护者，在 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**；随后在 **Actions → Deploy GitHub Pages → Run workflow** 选择 `main` 运行。只有代码推送权限的协作者无法完成首次站点设置。启用前构建可以通过，部署步骤会提示缺少 Pages 配置。

发布完成需同时确认工作流成功、线上页面及脚本/样式可访问。浏览器测试页仅供本地开发验证，不随 `dist` 发布；后端联调与正式业务部署仍按下文的接口和宿主契约进行。

## 功能与操作

### 图片术语

| 名称 | 含义 |
| --- | --- |
| 初始原图 | 进入本次编辑时的图片，用于“按住查看原图”和“还原初始”；上传新图不改变这一基准 |
| 当前底图 | 当前工作的基础图片，可能已上传替换或采用过消除结果；消除源图由它生成，并包含当前调色效果 |
| 编辑结果 | 当前底图叠加可见新增内容后合成的图片，用于提交替换任务图片 |
| 消除选区（Mask） | 单独提交的修改区域，不加入普通图层列表，也不进入最终成图 |

### 编辑能力

| 模块 | 行为 |
| --- | --- |
| 图片 | 宿主或 URL 提供进入编辑时的图片；“上传本地图片”仅接受实际可解码的 JPG/JPEG，成功后载入新草稿，保留上传图片原尺寸 |
| 绘制入口 | 左侧统一为“绘制”，面板顶部直接切换画笔／矩形／椭圆；首次默认画笔，本次编辑中记住最近绘制或选中的类型。选中对象显示“当前画笔／矩形／椭圆属性”，取消选择后保留绘制面板并显示对应“新…样式”。切换类型进入新绘制，不转换已有对象；三种类型共用最近设置的颜色和取色能力，其余属性按类型展示 |
| 消除笔 | 涂抹、矩形框选、自由圈选、多边形套索；圈选松手自动闭合，套索逐点点击并点击高亮起点闭合；支持添加/减去、顶部撤销/重做、清空选区、误触过滤、按住隐藏选区，选区完成后点击“开始消除”才提交；最终选区为空时禁用减选和提交 |
| 文字 | 面板“添加文字”创建后直接输入，双击已有文字继续编辑；字体、字号、加粗、斜体、对齐、颜色；可选不透明背景、背景颜色、留白和圆角；左右控制点调整文本框宽度，另有旋转控制点，不通过角点拉伸字形 |
| 更多文字设置 | 默认收起行距、字距、描边、阴影、本地字体；文字与背景作为同一对象移动、复制、删除及撤销。阴影未启用时也保留所选阴影颜色，之后调整模糊或偏移即使用该颜色；复制、撤销和重做均保留 |
| 字体 | 系统字体和本地 WOFF/WOFF2/TTF/OTF；加载完成后应用，导出和恢复前等待字体就绪 |
| 图形 | 矩形、椭圆；直接切换实心／边框，默认实心。边框下通过带线条示意的下拉选择实线／虚线／密虚线／圆点线／点划线，粗细支持滑块及数字输入 1–100px；颜色名称随样式显示为填充颜色／边框颜色，切换保留线型和粗细；矩形圆角支持数字输入及滑块，0 为直角；新建预设为 0–500px，绘制完成时限制到短边的一半，已有矩形的输入与滑块上限随尺寸同步。画笔粗细、边框粗细、矩形圆角均显示 px 单位。不透明度支持滑块及数字输入 0–100%，初始默认 100%，实心和边框均可调整。Shift 绘制正方形／圆形，创建后仍可改属性 |
| 画笔 | 平滑、不透明笔画，粗细名称与数字框、px 单位同一行，下方为滑块，范围 1–300px，Shift 画直线；每笔独立成层，创建后可修改颜色和粗细；拉伸只改变笔迹范围，粗细始终按面板像素值保持，复制和历史恢复保持一致；滚轮继续用于缩放 |
| 颜色 | 常用色直接应用；自定义入口回显当前颜色，紧凑面板优先放在属性栏内以保留画布预览。提供色板、色相及输入框左侧的 HEX／RGB／HSL 切换，默认 HEX：六位 HEX 可省略 #、不区分大小写；RGB 为 0–255 整数，HSL 的 H 为 0–360°、S/L 为 0–100%，支持小数。切换格式不改变颜色；无效输入不应用，保留上次有效预览。支持实时预览、原色对照、应用和取消；点击“原颜色”恢复打开面板时的颜色，可继续试色，仍需应用才确认。应用记一步历史，取消、Esc 或点击外部恢复原色，不穿透操作画布；新建样式不记历史。图片取色带像素放大镜，作用于开始取色的对象或新建样式；弹窗内取色回到颜色草稿后仍需应用，Esc 只取消本次取色并完整保留输入、格式及色板位置（包括无效输入） |
| 图层 | 类型、颜色和名称识别；选择、隐藏、锁定、排序、复制、删除及问题定位，详见下方图层说明 |
| 调色 | 亮度、对比度、饱和度、色温、锐化；颜色叠加；八种可调强度的滤镜。仅作用于当前工作底图，新增文字、图形和画笔保持原属性；实时预览、单步撤销与重置，详见下方说明 |
| 查看 | 进入编辑默认选中消除笔；支持切换选择/平移、按住空格临时平移、自动适配、100% 查看及滚轮以指针位置缩放，缩放范围 3%–400% |
| 编辑历史 | 撤销/重做、调色状态一起恢复、还原初始图片可撤销；初始图片对比不改变编辑状态 |
| 替换图片 | 有内容修改或已上传图片时启用；按当前图片物理尺寸合成 JPG，无透明通道，排除临时选区和隐藏图层；通过宿主完成检测和保存后返回审核，不另设导出入口 |

文字采用**按字符折行**，英文长词可能拆行；这不是完整的专业中英文排版引擎。字体仅保留在当前页面会话中，需自行确保所用字体可用于目标用途。

文字、画笔、矩形、椭圆及多选外框统一使用蓝色边框、白底蓝边控制点，移动时不淡化边框。控制点保持原尺寸：文字仍通过左右控制点调宽并支持旋转，画笔和图形保留原有缩放及旋转方式。选中框仅用于编辑，不进入成图。

文字工作区顶部提供“添加文字”：每次点击创建一段文字，放在当前可见图片区域中并直接输入，可拖动调整位置；如果图片已完全移出视野，先适配图片再添加。画布点击不再新增文字。点击空白处结束输入并取消选择后，仍停留文字工作区，不改变属性栏的展开或收起状态。选中文字时显示“当前文字属性”，未选中时显示最近使用的“新文字样式”，调整只作用于下一次新增。选中其他文字回显其实际属性，选中图形展示图形属性；字体、字号、颜色等直接可见，其余仍在“更多设置”中。

连续添加时，新文字与附近可见文字适当错开，优先向右下方偏移；到达边缘后改用附近可容纳的位置，避免越加越远。偏移量随缩放换算，在屏幕上保持相近距离，不改变已有文字的位置。短时间误连点不重复创建，正常再次点击仍可添加；新文字立即选中并输入，提示当前文字数量，已展开的图层列表定位到新图层。大字号超出可见范围时优先让新文字中心可见，不擅自缩小字号。

### 调色

面板按**基础调节 → 滤镜 → 颜色叠加 → 重置调色**排列。基础调节和滤镜直接可见，颜色叠加默认折叠，收起时仍回显已启用的强度；所有效果只作用于当前底图，选中新增对象不改变调色的作用目标。

| 设置 | 范围与操作 |
| --- | --- |
| 亮度、对比度、饱和度 | −100～100，默认 0；分别调整明暗、明暗差异及色彩浓淡 |
| 色温 | −100～100，默认 0；负值偏冷、正值偏暖，是相对冷暖调节，不显示开尔文数值 |
| 锐化 | 0～100，默认关闭；温和增强边缘与纹理，不能恢复失焦图片 |
| 滤镜 | 无滤镜、清透、明亮、柔和、鲜明、暖阳、清冷、黑白、复古；同时仅一个滤镜生效，强度 0～100%，初始 100%。切换滤镜保留其他调节和滤镜强度；“无滤镜”只取消滤镜 |
| 颜色叠加 | 复用常用色、自定义 HEX／RGB／HSL 与图片取色；强度 0～100%，初始为 0%，选择颜色后调高强度查看效果。“取消叠加”只将叠加强度归零，保留所选颜色 |

滤镜使用当前底图的低分辨率效果缩略图，按基础调节和叠加后的图片预览 100% 滤镜强度；切换底图重新生成，过期结果不覆盖新图。处理顺序固定为基础调节、颜色叠加、滤镜，从底图源像素重新计算，不反复累计效果。黑白、复古统一归入滤镜，已移除整图模糊；本轮不提供分色 HSL、高光、阴影、绿红色调或混合模式。

滑块实时预览，松手、键盘松键或失焦时一次调整记一步历史；数字输入在回车或失焦时应用，Esc 取消草稿并保留输入焦点。自定义叠加颜色实时预览，应用记一步历史；取消、Esc 或点击外部恢复原色。取色遵循现有颜色面板规则，不修改新增对象。

“重置调色”一次清除基础调节、颜色叠加和滤镜设置，可整体撤销；不删除新增内容，也不撤回已经采用的消除结果。“按住查看原图”仍以进入本次编辑时的图片为基准，与重置调色区分。

当前效果进入消除源图和最终成图；采用消除结果后将已烘焙的调色参数重置，避免重复叠加。撤销采用恢复原底图、选区和整套参数；上传新图清空调色。滤镜主要复用 Fabric.js 原生处理，色温与滤镜强度采用颜色矩阵，锐化在原生卷积基础上对齐 CPU 与 GPU 的边缘取样。

### 操作区与原图对比

左侧高亮表示所属工作区，底部“选择／平移”高亮表示鼠标操作，两者独立。矩形、椭圆松手后保持当前绘制类型和新建样式，不选中新对象、不显示控制框，可直接拖动继续画；每个图形独立成层并可逐步撤销。要修改已有图形，点击底部“选择”后点选，或直接从图层选择。“绘制”和底部“选择”此时同时高亮；在选择模式点击空白取消选择不会自动恢复绘制，再次点击类型才继续画。画笔仍支持连续多笔，选中已有笔画后可改其属性，取消选择后回到新画笔样式。新建样式仅用于下一次新增，不改变已有内容或产生历史。绘制类型入口在属性区域滚动时保持可见；面板收紧纵向留白，圆角与操作提示在较矮窗口中可向下滚动查看。

删除、隐藏或锁定导致选择解除时，也保留所属工作区。多选面板标题显示“已选 X 个图层”，正文先说明一起移动、缩放和旋转，再以次要文字提示单选后可编辑属性；不显示某个对象的属性或新建样式，删除仍使用右侧图层操作。多选不另行改变工作区高亮和面板展开状态，恢复单选后显示对象属性。选择／平移切换保留对象选择、工作区和视野；多选切到平移时改为返回选择的引导。消除工作区切到选择／平移后，显示当前模式、“返回消除笔”入口，以及已保留的消除方式、选区操作、笔刷大小（涂抹模式）和选区状态摘要，替代整组禁用控件。点击返回或左侧消除笔恢复完整设置及已完成选区，不自动消除；按住空格临时平移仍保留原消除面板。

矩形拉伸时，圆角按图片像素保持，拖动中的预览与松手结果一致；缩小时最多为当前短边的一半，同一次拖动重新放大可恢复原圆角，松手后保存最终有效值。拉伸、复制、撤销／重做与最终成图均沿用此规则。

一笔绘制、一个图形、一次移动或尺寸调整各记一步历史。已有笔画粗细、图形边框粗细／不透明度／矩形圆角和调色滑块拖动时实时预览，松手、键盘调整结束、取消指针或失焦时收尾，一次连续调整对应一次撤销。撤销／重做尽量保留仍存在且可编辑的选中对象，回显恢复后的属性；对象不再存在、隐藏或锁定时解除对应选择，保留工作区。仅切换工具、选择对象或查看图片不记录历史。

绘制图形时显示深色细线与白色衬线组成的辅助轮廓，浅色和深色背景上都可定位；完成后辅助轮廓消失，保持连续绘制；主动选中已有对象时显示控制框。辅助线仅用于编辑预览，不进入成图或取色结果。画笔光标按实际粗细和缩放显示范围，始终保留深浅对比轮廓，白色画笔在白底上也能定位；范围过小时补充小十字定位点，不改变笔画粗细。矩形、椭圆按屏幕拖动距离过滤轻点和抖动，同时要求宽高均大于零；明确拖出的细长图形仍可创建，画笔点击画圆点保持可用。三种绘制类型继续共用最近设置的颜色，实心／边框不分别保存颜色。

图形不透明度只影响当前矩形或椭圆，不影响底图、文字或画笔；100% 完全不透明，降低后透出下方内容，0% 仍保留图层，可从图层列表选中恢复；图层行标记“完全透明”，新建样式为 0% 时明确提醒后续绘制不可见。空心图形内部允许点选下方内容，边线附近保留约 4 屏幕像素的点击容错；完全透明图形不拦截画布点选。切换实心／边框保留不透明度、线型和粗细，复制及撤销／重做保留这些属性。下拉收起时显示当前线型名称和示意，展开后用统一深色示意展示五种线型及当前勾选；悬停或方向键仅浏览，点击或回车／空格才应用，Esc 只关闭菜单并返回入口焦点。线段与间隔随粗细缩放，圆点使用圆形端点；旧虚线保持原效果。

画笔、矩形和椭圆绘制期间暂停滚轮缩放，松手后恢复。画笔粗细、边框粗细、图形不透明度和矩形圆角的数字输入以回车或失焦应用；Esc 恢复本次输入前的值并保留输入框焦点，取消不记历史，也不触发关闭编辑。

| 位置 | 操作 |
| --- | --- |
| 左侧工具栏 | 消除笔、绘制、文字、调色 |
| 左侧工具属性 | 初始展开消除笔设置，之后按当前工具或选中对象显示属性，可手动收起 |
| 左下角帮助 | 按需查看编辑快捷键，Esc 或关闭按钮返回编辑 |
| 左上角 | 撤销、重做、还原初始、按住查看原图，依次排列 |
| 右上角 | 上传本地图片、替换图片、关闭编辑；上传入口与主操作分隔显示 |
| 画布右下角 | 选择/平移、缩放、原图对比、图层展开/收起，按四组排列 |

右上角在上传入口前以灰色文字显示当前工作图片的宽高，例如“1280 × 800 px”，不使用按钮底色或边框。悬停说明宽高顺序及缩放不改变实际尺寸；上传新图片后按新图尺寸更新，原图对比和画布缩放不改变这一显示。窄窗口下隐藏尺寸信息，优先保留操作按钮。

左上角和画布右下角的操作以图标为主；缩放区依次为减号、当前比例、加号、100% 数字和适配图标。当前比例固定宽度、使用等宽数字；100% 用于查看细节，适配使用四角框住中心方形的图标，悬停或键盘聚焦说明“完整显示图片并居中”。到达 3% / 400% 时禁用对应缩小 / 放大按钮，并提示已到极限。悬停或键盘聚焦提供提示，模式和查看状态高亮。选择、平移互斥，点击选择可退出绘制并调整对象；平移提示保留按住空格临时拖动画布的用法。

左侧不再常驻“编辑设置”说明页，也不因取消选择退回空白“工具属性”。进入编辑时默认选中消除笔并展开设置，初始无选区，不自动消除；“开始消除”在有效选区完成前禁用。点击工具或重新选择已有对象时展开对应属性；画布上的选择、拖动等手势结束后才展开，避免操作中改变画布宽度。取消选择、删除、显隐／锁定、选择／平移切换及撤销／重做均保持属性栏原有展开或收起状态；手动收起后可再次点击工具或重新选择对象展开。面板切换保持缩放、画布中心对应的图片位置及对象选择，不修改草稿，也不改变右侧图层面板的收起状态。消除笔面板内的流程和提示保持不变。

左侧顺序保持消除笔、绘制、文字、调色。有新增内容时，切换到消除笔提示“仅消除底图内容；新增文字和绘制内容暂时隐藏，退出后恢复原有显示。”；切换到调色提示“仅调整底图；新增文字和绘制内容保持不变。”。直接进入工具，提示沿用画布上方约 5 秒自动收起的反馈，不要求确认、不移动画布；没有新增内容或重复点击当前工具不追加提示。切换取消了未完成选区时，优先保留取消提示。

绘制说明放在对应属性面板，区分新绘制、调整已有对象和返回绘制。“已撤销”“已删除”等普通反馈浮在画布上方，5 秒后自动收起，也可手动关闭；错误及检测拦截等需处理信息持续保留。提示出现、换行或关闭不改变画布尺寸，不再常驻通用顶部提示条。

通用快捷键通过左下方“帮助”查看，不再重复放在各属性面板中；取色、文字编辑、选区等必要提示仍留在对应操作旁。鼠标在帮助按钮上停留 300ms 后，在按钮右侧约 8px 处显示“操作说明与快捷键”；键盘聚焦也可查看。打开帮助立即隐藏提示，关闭按钮或 Esc 返回入口焦点后不自动重现；鼠标移开再移入或键盘重新聚焦时可再次查看。帮助弹窗中的按键不会触发画布编辑。

两处原图对比入口共用“按住查看原图”状态：左键按下立即查看，松开返回，单击不锁定。按钮聚焦后支持按住空格或 Enter；移出后松手、失焦、页面隐藏、指针取消或丢失捕获都会结束查看。同尺寸图片沿用当前缩放及位置；上传后尺寸不同则临时适配初始原图，结束时恢复工作视图及原适配状态。查看期间两处图标同步高亮，画布提示“正在查看原图 · 松开返回编辑”，不改变编辑草稿。

### 图层

- 每行展示类型图标、颜色、名称及显示/锁定按钮。文字名称跟随实际文案摘要，矩形、椭圆和画笔分别编号；底图显示实际图片缩略图。仅在隐藏、锁定或文案异常时补充状态。
- 底图固定在列表最下方，不参与普通图层的选择、排序、复制和删除。新增对象均为图片内容，无用途切换。
- 隐藏图层不参与成图；锁定只防止误编辑，不改变成图可见性。两种状态可同时存在，点击名称不会自动显示或解锁。
- 隐藏或锁定未选中的图层，保留当前选择；多选中操作其中一层，仅移除受影响的选择，其余对象的位置不变。
- 底部依次提供置顶、上移一层、下移一层、置底，与复制、删除适当留白。排序针对单个可编辑图层；置顶移到全部新增内容上方，置底移到全部新增内容下方但仍在底图上方。到顶/到底时禁用对应方向的两个按钮，无选择或多选时禁用排序。排序直接生效，一次记一步撤销，保留选择与画布视野。复制针对单个选中图层；多选时显示数量并明确删除范围。删除支持撤销，不另弹确认框。
- 面板默认展开，右下角可收起并释放空间，本次编辑内记住状态；切换工具或新增内容不自动展开。面板切换保持缩放、图片中心和对象选择，对比期间切换后也能恢复编辑视图；未完成绘制、取色或载入等受限状态下暂不可切换。
- 面板展开时，新增、复制或选中对象会仅滚动列表定位，不移动画布。校验失败且返回有效图层 ID 时，提示中提供“查看问题图层”；点击后展开、定位并聚焦该行，保留隐藏/锁定状态和画布缩放。
- 消除模式下，有新增内容时图层面板提示“当前仅预览底图，新增内容已保留”，不通过改写眼睛开关实现临时预览。

### 上传、替换与确认

“上传本地图片”仅载入编辑草稿，不立即替换任务图片；“替换图片”才通过宿主检测并保存编辑结果，成功后返回审核。

上传成功后默认选中消除笔，左侧已展开时显示消除设置，手动收起时保持收起；取消选择、取消载入确认或上传失败，保留原来的工具与面板状态。载入图片不会自动开始消除。

| 操作 | 确认与恢复规则 |
| --- | --- |
| 替换图片 | 提醒替换后不可恢复，用户确认后才开始检测和保存；编辑器不提供已提交替换的撤销入口 |
| 还原初始 | 提醒将恢复初始原图；确认后执行，可通过撤销恢复还原前的草稿 |
| 上传、关闭、切换编辑图片 | 存在未保存修改、未完成选区或待处理/待采用结果时提醒；取消保留当前草稿 |

上述操作统一使用页面内确认弹窗：默认聚焦取消，Esc 和关闭按钮等同取消，点击遮罩不关闭；等待确认时锁定编辑，重复确认只执行一次，晚到的消除结果不会抢占弹窗。浏览器刷新或关闭标签页仍使用原生离开提醒，结果预览和提交进度弹窗保留各自规则。

### 消除选区

进入消除选区时固定显示并提交当前工作底图，后加文字和图形不参与消除。这个隔离**不修改已保存的图层显隐属性**；退出工具后恢复原有显示。

四种选区的操作约定：

- 涂抹：滑块或数值输入调整大小，范围为原图 4–300px；数值回车或失焦生效，Esc 取消本次输入，空值恢复原值，越界值自动限制到范围内。一笔内大小固定。光标圈表示笔刷的实际覆盖范围。
- 框选：拖动中按住空格可移动选框，松开空格后继续调整大小；移动限制在图片内。未开始框选时，空格仍用于平移画布。
- 圈选：拖动时只显示轨迹与首尾连接预览，松手后闭合并填充；保留图外拖动与松手位置，完整路径按图片边界裁切，预览和导出使用相同路径。交叉路径按图内实际填充面积判断是否有效，图外面积不计入。
- 多边形套索：至少三个顶点后才启用起点闭合吸附，吸附范围随选区尺寸和邻近顶点距离缩小，避免小选区提前闭合；顶部撤销、Ctrl+Z、退格均可撤销上一点，Enter 完成，Esc 取消；草稿期间禁用重做和初始对比。按钮获得焦点时，回车和空格优先操作按钮，不触发画布快捷键。
- 消除笔面板内的“按住隐藏选区”在按住时显示“松开显示选区”，临时隐藏选区遮罩，保留当前工作底图；松手、移出后松手、窗口失焦或操作取消后恢复，不清空选区。按钮获得焦点时也支持按住空格或 Enter；无有效选区或选区尚未完成时禁用。它与两处“按住查看原图”入口不同，后者查看初始原图。
- 不额外维护添加/减去次数，选区历史统一记录操作。有效选区按与导出相同的二值阈值检查最终像素；完全减空后禁用开始消除，撤销后重新判断。

选区收尾与异常操作：

- 涂抹、框选、圈选完成前采集松手位置，只有发起操作的左键松开才完成选区；不同指针和其他鼠标键不能提前结束。操作取消、窗口失焦只取消草稿，不清除完成的选区。
- 涂抹离图时画至边界后暂停，回图后从边界继续，但不跨图外空白连接、不沿边缘追踪鼠标。分段轨迹仍是一笔，预览、撤销、重做和导出 Mask 使用相同断点。
- 重复点击当前工具或当前添加/减去模式不改变草稿；真正切换时取消未完成部分并提示，已完成选区保留。
- “清空选区”清除本轮选区并回到添加模式，保留工具、笔刷大小；可通过顶部撤销恢复。减空后自动回到添加模式；无选区时不能减选。
- 未改变已有遮罩的减选不新增历史。判断实际透明度变化，保留可能影响后续编辑的细微边缘变化。
- 已完成选区统一通过顶部撤销/重做及对应快捷键操作；面板仅在套索草稿期间提供“撤销上一点”，不再提供含义不同的“撤销上一步”。
- 轨迹、笔刷圈及套索节点增加浅色对比描边；无效小选区提示放大图片后重选。

面板从上到下为：四种选区类型、当前类型提示、添加/减去、涂抹时的笔刷大小、按住隐藏选区、清空选区和开始消除。框选明确提示“拖动框选；松手前按住空格可移动选框”；圈选说明松手自动闭合。套索提示随顶点数量更新，不足三点时引导继续加点，至少三点时提示点击起点或按 Enter 闭合；仅草稿期间显示“撤销上一点”。减去模式额外提示从已有选区中减去无需消除的区域；无选区时说明需先选择区域，未完成选区时不能提交。

有新增文字或绘制对象时，在面板轻提示“当前仅显示底图，新增文字和绘制内容已保留”，无新增内容或正在对比初始图片时不显示。普通选区完成不重复提示；取消、无效减选等反馈浮在画布上方，5 秒后收起，不改变画布尺寸。失败及服务未接入时持续显示原因并说明图片、选区已保留，直到用户关闭提示或后续操作更新。处理期间显示“正在消除…”及“取消等待”，取消后保留原图片和选区。

### 消除结果预览与采用

1. 消除笔固定提交当前工作底图和同尺寸 Mask；不合并后加文字和图形。
2. 提交时固定文档 ID、修订号及输入快照；同一文档只运行一个消除请求。
3. 请求期间暂时锁定内容编辑，允许取消等待或确认后上传替换图片。新图片校验、载入成功才清空旧草稿并隔离旧请求；上传失败保留旧草稿。取消等待不承诺后端停止计费或生成。
4. 返回单个结果后先展示消除前/消除后，不立即覆盖文档；对比两侧保留相同的可见新增内容，操作规则见下表。使用消除结果仅更新编辑草稿，仍须点击右上角“替换图片”才保存到任务。
5. 使用结果时只替换底图，后加文字和图形保留可编辑，隐藏图层也保留。
6. 采用时清除本次选区，并重置已烘焙进源图片的调色参数；整体操作可撤销。采用后继续停留在消除笔，保留选区工具和笔刷大小，回到添加模式，可直接开始下一轮。
7. 放弃／失败保留原内容与选区。旧文档、旧修订或已取消的结果不能写回当前文档。

| 预览操作 | 行为 |
| --- | --- |
| 缩放和平移 | 两侧共享查看位置，在任意一侧操作即同步；提供缩小、放大、100% 和适配，滚轮以指针位置缩放，视图聚焦后可用方向键平移 |
| 初始视图 | 默认适配且不放大小图，最大 400%；查看方式不改变实际成图或尺寸 |
| 预览加载失败 | 两张图均加载完成后才可采用；“重新加载预览”沿用已有图片，不重新发起消除 |
| 采用失败 | 在弹窗内提示，保留图片、选区和待采用结果，可“重试使用结果” |
| 放弃 | 仅点击“放弃结果”才放弃，Esc 不关闭结果弹窗；画布中的 Esc 仍可取消未完成绘制 |

当前版本只接受**与输入同宽同高**的结果。尺寸不一致时拒绝采用，不擅自缩放或重新定位已有图层。
选区外像素是否保持、商品一致性、生成质量仍属于前后端联调验收范围，前端不会据此宣称模型只修改了选区。

## 消除接口

适配器见 [src/lib/eraseApi.ts](./src/lib/eraseApi.ts)。以下是**当前前端适配器约定，尚需后端确认和实现**，不是已上线接口说明。

### 环境配置

```dotenv
VITE_ERASER_API_URL=
VITE_DEFAULT_IMAGE_URL=
```

`VITE_ERASER_API_URL` 为消除请求地址，`VITE_DEFAULT_IMAGE_URL` 为独立预览的默认图片地址。不要在前端环境变量中放入服务端密钥；鉴权、权限与审核回流需在实际系统接入时定义。跨域图片和接口需要正确的 CORS 配置。

### 输入范围与请求

`editorRole` 区分文字、图形、绘制等对象类型，`editorPurpose` 仅区分底图 `base` 和新增内容 `content`。

| 对象 | 最终 JPG | 消除源图片 |
| --- | --- | --- |
| 当前底图（包含当前调色效果） | 参与 | 参与 |
| 新增文字、图形、自由绘制 | 可见时参与 | 不参与，采用消除结果后保持独立可编辑 |
| 消除选区 Mask | 不参与 | 作为独立 `mask.png` 提交 |

消除接口使用 `POST multipart/form-data`：

| 能力 | 环境变量 | 字段 |
| --- | --- | --- |
| 消除 | `VITE_ERASER_API_URL` | `image`、`mask`、`metadata` |

- `image`：从当前工作底图生成的 `image.jpg`，包含当前调色效果，使用当前图片物理尺寸和白色背景；不是固定重传初始原图，也不合并新增图层。
- `mask`：`mask.png`，与源图同尺寸，覆盖度阈值为 128，所有像素严格为不透明黑色 `(0,0,0)` 或白色 `(255,255,255)`；白色修改，黑色保留。减选通过几何合成后统一二值化。不发送有损 JPEG Mask。选区按用户实际涂抹、框选或圈定的范围合成，不额外向外扩大。
- `metadata`：版本、消除操作、底图范围、尺寸和前端会话标识，示例见下。前端 ID 不是审核系统任务 ID 或鉴权凭证。

```json
{
  "schemaVersion": 1,
  "mode": "erase",
  "target": "base",
  "width": 1280,
  "height": 800,
  "documentId": "document-...",
  "revision": 6,
  "coordinateSystem": "0-1000",
  "bboxOrder": "ymin,xmin,ymax,xmax"
}
```

### 响应与联调

支持的返回方式：图片 Blob，或 JSON 中的 `url`、`imageUrl`、`resultUrl`、`image`、`base64`，这些字段也可以放在 `data` 下。支持 base64 Data URL、纯 base64；结果 URL 支持 HTTP(S)，相对路径以接口地址解析。当前只取一个结果，不包含多候选或消除任务轮询协议。

联调需核对请求字段、鉴权/CORS、返回图片可读取性、同尺寸要求、失败与取消后的重试，以及选区外像素和商品一致性。接口有响应不等于上述验收已完成。`metadata` 中的前端会话标识不能替代宿主业务 ID 或鉴权。

## 宿主系统接入

接入类型见 [`src/integration.ts`](./src/integration.ts)。React 宿主传入稳定的 `integration` 对象：`<App integration={adapter} />`；独立入口可在加载 `main.tsx` 前设置 `window.pixelweaveIntegration`。适配器变化会重新初始化编辑会话，不要在每次父组件渲染时新建适配器。

| 字段/方法 | 宿主责任 |
| --- | --- |
| `initialImage`、`context` | 提供当前图片和稳定的业务任务 ID、图片 ID、可选当前替换记录 ID；权限由宿主校验，不能以页面生成的 ID 代替 |
| `validateTexts(texts, context)` | 检查所有仍保留的非空新增文案，包括隐藏图层；无新增文案时跳过此调用。返回未通过原因，可带 `objectId` 定位对应文字图层 |
| `replace(input, progress)` | 接收最终 JPG Blob、尺寸、来源、全部新增文案和 `submissionId`；完成实际成图检测、OCR/文字检查、人物识别、必要标识写入及保存。可回报用户可读的处理进度 |
| `confirmResult(submissionId, context)` | 查询同一次提交的最终结果，不创建新的替换任务 |
| `onClose(result)` | 放弃时返回原审核页面；成功时按 `recordId` 更新当前生效图片和审核状态，保留审核位置。刷新完成后才关闭编辑界面 |

提交前锁定编辑并检查新增文案，再合成 JPG、验证实际编码和尺寸。仅选区变化不能提交，消除处理中或结果尚未采用时也不能提交。上传来源为 `upload`，不携带原图的 `baseRecordId`，但保留本次编辑的任务和图片目标；在线编辑来源为 `online`。

宿主的保存流程须保证：保留原始图片与历史成功替换记录，只更新最新生效图片；新图进入待审核状态，旧图上的评分和审核结论不能直接沿用。真实检查规则、标识方式、保存接口和审核字段以业务系统为准，本仓库没有实现这些服务。

替换结果约定：

- `succeeded` 必须带已持久化的 `recordId`；`failed` 必须表示明确失败且后续不会再产生该次保存效果；尚不确定时返回 `pending`。
- `replace` 发出后发生网络异常，前端按结果未知处理，保留同一个 `submissionId`，锁定编辑、上传、关闭和重复提交；用户点击“确认替换结果”调用查询接口。宿主须按该 ID 保证幂等及可靠查询，不能把超时直接解释为保存失败。
- 检查或明确保存失败后，解锁并保留草稿；返回有效 `objectId` 时，对应文字图层标记“文案需修改”，可通过“查看问题图层”展开并定位，隐藏/锁定属性保留。
- 保存成功但审核刷新失败时，保留成功记录，只重试返回审核，不再次保存。外部强制卸载组件时，宿主仍需负责追踪已发出的任务与业务目标，不能依赖前端忽略回调来取消后端保存。

## 会话与限制

- 历史只保存对象和图片资源 ID，不在每一步复制图片 Base64。仅选区变化时，撤销/重做直接恢复选区，复用现有图片及图层对象；涉及图片、对象、调色或尺寸变化时完整恢复，历史顺序保持一致。
- 最多 50 个历史快照，并按 256 MiB 的资源/快照估算预算回收较旧历史；初始图片、当前文档、待采用结果和仍在处理的请求资源保持引用。
- 上述是历史缓存预算，不是浏览器进程内存硬上限；解码、渲染、合成还会产生临时内存。上传不额外设置文件大小、像素或尺寸上限，也不自动压缩尺寸；实际仍受浏览器解码、画布和内存能力约束，载入失败保留当前草稿。
- 上传需同时满足 JPG/JPEG 后缀、JPEG 文件特征和实际可解码；不依赖 MIME 声明判断。取消选择、取消放弃确认、格式错误或载入失败均保留旧草稿。成功才清空旧图层、调色和选区并重置当前撤销历史。
- “按住查看原图”及“还原初始”始终指进入本次编辑时的图片，上传后也不改变该基准。还原需确认，且可以撤销回还原前的草稿。
- 有草稿、生成任务或待采用结果时，关闭编辑需确认；页面关闭/刷新会提醒未保留的编辑。替换处理中或结果未知时不能从编辑器关闭。
- **尚未实现跨会话草稿或可编辑工程保存**。不要把本地撤销历史理解为审核系统的持久化替换记录；后者由接入的宿主服务负责。

当前不包含整体/局部指令改图（后续另行规划）、箭头与编号、OCR 去字与文字图层重建、自动对象/Logo 识别、图片翻译、裁剪/改尺寸/扩图、专业生成式图层及多候选消除结果。
